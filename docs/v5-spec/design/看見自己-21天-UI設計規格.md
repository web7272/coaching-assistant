# 看見自己 21 天 · UI 設計規格

> 給工程師 / PM / 設計師的共用 reference。本文件涵蓋色彩、字體、元件、版面、轉場、互動規則、響應式注意事項。

---

## 設計哲學（先讀這段）

這個 App 不是 chatbot，是「思考的空間」。所有設計決定以下面五個原則為準。違反任何一條會直接破壞產品的靈魂：

1. **紙感，不是 App 感。** 視覺語言來自紙、書、信件，不是 SaaS dashboard。
2. **學員的話是主角，教練是配角。** AI 從不替學員選詞、總結、評論。
3. **沉默被設計，不被消除。** 等待、停頓、留白都是內容的一部分。
4. **沒有 gamification。** 不出現 streak、進度條、徽章、勳章、"X/21" 計數。
5. **同一個視覺語法貫穿到底。** active / revealed / future 三狀態套用在所有 cell 上。

## 一、色彩系統

統一以 CSS Custom Properties 實作。

```css
:root {
  /* 背景 */
  --bg-primary:    #FAF7F2;  /* 整體頁面背景 */
  --bg-card:       #FFFBF4;  /* 卡片 / 筆記 / 紙面 */
  --bg-bubble:     #F0EAE0;  /* 使用者訊息泡泡 */
  --bg-callback:   #F5EFE4;  /* 召回卡片：學員過去的話 */

  /* 邊框 */
  --border-revealed:  #E8DFCD;  /* 普通已揭開狀態 */
  --border-active:    #C9B69D;  /* 當天 / 剛遞出狀態 */
  --border-future:    #ECE5D6;  /* 未來狀態 */
  --border-separator: #EFE9DC;  /* 微小分隔線 */

  /* 文字 */
  --text-primary:    #2C2825;  /* 主要文字、AI 訊息、cell 短句 */
  --text-secondary:  #8B7B65;  /* 簽名、active day number、小提示 */
  --text-tertiary:   #A8A097;  /* 副標 */
  --text-quaternary: #B5AEA2;  /* revealed day number、placeholder */
  --text-faint:      #D4CDC1;  /* future day number、結業卡 future */

  /* 強調 */
  --accent-sage:     #8FA68E;  /* ✦ 標記，整個產品唯一的彩色 accent */
}
```

### 嚴格禁用

- 純黑 `#000`、純白 `#FFF`、亮藍 `#0066FF`、任何螢光 / 飽和色
- 紅色錯誤訊息、綠色成功訊息（不能用紅綠 status colors）
- 漸層、陰影、半透明模糊（無 `box-shadow`、無 `backdrop-filter`）

所有顏色都在「暖米白 → 暖灰棕 → 暖深棕」這條色軸上，加一個霧綠 ✦ 做唯一 accent。

## 二、字體系統

```css
:root {
  --font-serif: 'Noto Serif TC', 'Songti SC', 'Songti TC', serif;
  --font-sans:  'Noto Sans TC', 'PingFang TC', sans-serif;
}
```

### 字體分工（極重要原則）

- **`--font-serif` 宋體 = AI / 產品在說話。**
  所有 AI 訊息、教練筆記、週報、結業、按鈕文字、頁面標題、小提示、簽名都用宋體。
- **`--font-sans` 黑體 = 學員在打字 / 數字標記。**
  使用者輸入框、user message bubble、cell 上的日期數字、ambient indicators 都用黑體。

整個 App 從 entry 到 graduation，**宋體 = 它 / 黑體 = 你** 這個視覺語法絕對不打破。

### 字級表

| 用途                | font        | size       | weight | letter-spacing | line-height |
| ------------------- | ----------- | ---------- | ------ | -------------- | ----------- |
| 產品名（入口）      | serif       | 32px       | 400    | 8px            | 1.2         |
| 頁面標題（你的旅程） | serif       | 24px       | 400    | 4px            | 1.2         |
| AI 訊息 / 對話      | serif       | 19px       | 400    | 0              | 1.95        |
| 筆記內文            | serif       | 16.5px     | 400    | 0              | 2.0         |
| 週報 / 結業 body   | serif       | 16px       | 400    | 0              | 1.95        |
| 宣言（結業）        | serif       | 19px       | 400    | 1.5px          | 2.1         |
| 結業 21 句詩        | serif       | 13px       | 400    | 0.5px          | 2.4         |
| 使用者輸入 / bubble | sans        | 15px       | 400    | 0              | 1.65        |
| Cell 短句           | serif       | 12.5–13.5px | 400   | 0.3–0.5px      | 1.2         |
| Day number          | sans        | 9px        | 400    | 0              | 1           |
| ✦ accent           | sans        | 9px        | 400    | 0              | 1           |
| 副標 / 提示（italic）| serif italic | 11–13px   | 400    | 0.5–3px        | 1.4         |
| 簽名（italic）      | serif italic | 14px      | 400    | 0.5px          | 1           |
| 按鈕                | serif       | 14px       | 400    | 2–3px          | 1           |

### Italic 使用規則

宋體在中文渲染時會被瀏覽器強制傾斜（faux italic）。**只在下列情境用 italic**：
- 「— 教練」「— 教練見證」簽名
- 「沒有對的答案」「慢慢來」「今天就到這裡了」這類小提示
- 「今天」cell label
- 「第一週」副標
- 「✦ 已收下」status text

**避免**在大塊內文 / 標題使用 italic。

## 三、Cell 元件規格（核心元件）

整個 App 共用一個 Cell component，只有 props 不同：

```typescript
type CellProps = {
  type: 'daily' | 'weekly' | 'graduation';
  state: 'future' | 'active-empty' | 'active-filled' | 'revealed';
  content?: string;     // daily: 短句 | weekly: 'I' | 'II' | 'III'
  dayNumber?: number;   // 只有 daily cell 用
  onClick?: () => void; // active 跟 revealed 可點，future 不可點
};
```

### 基本樣式

```css
.cell {
  height: 64px;
  border-radius: 8px;
  display: flex;
  justify-content: center;
  align-items: center;
  position: relative;
  box-sizing: border-box;
  transition: background-color 250ms ease-out,
              border-color 250ms ease-out;
}
```

寬度由 grid 決定（見頁面 layout）。

### 四種狀態

| State           | background    | border                              | day# color           | ✦ 角標 | 中央內容                                          |
| --------------- | ------------- | ----------------------------------- | -------------------- | ------ | ------------------------------------------------- |
| `future`        | transparent   | `0.5px solid var(--border-future)`  | `--text-faint`       | none   | none                                              |
| `active-empty`  | `--bg-card`   | `0.5px solid var(--border-active)`  | `--text-secondary`   | yes    | "今天" — serif italic 12.5px `--text-secondary`   |
| `active-filled` | `--bg-card`   | `0.5px solid var(--border-active)`  | `--text-secondary`   | yes    | 短句 — serif 13px `--text-primary`                |
| `revealed`      | `--bg-card`   | `0.5px solid var(--border-revealed)` | `--text-quaternary` | none   | 短句 — serif 13px `--text-primary`                |

### Day number 定位

```css
.cell__day-num {
  position: absolute;
  top: 6px;
  left: 8px;
  font-family: var(--font-sans);
  font-size: 9px;
}
```

### ✦ accent 定位

```css
.cell__star {
  position: absolute;
  top: 5px;
  right: 7px;
  font-family: var(--font-sans);
  font-size: 9px;
  color: var(--accent-sage);
}
```

### Weekly cell 特殊內容

Weekly cell 不顯示 day number，中央放 Roman 數字 (I / II / III)：

```css
.cell--weekly .roman {
  font-family: var(--font-serif);
  font-style: italic;
  letter-spacing: 1px;
}
.cell--weekly.cell--active .roman   { font-size: 18px; color: var(--text-primary); }
.cell--weekly.cell--revealed .roman { font-size: 18px; color: var(--text-secondary); }
.cell--weekly.cell--future .roman   { font-size: 16px; color: var(--text-faint); }
```

### Graduation cell 特殊性

`type: 'graduation'` 的 cell 在 grid 外，全寬橫條：

```css
.cell--graduation {
  width: 100%;
  height: 56px;
  /* state 樣式同上 */
}
.cell--graduation .label {
  font-family: var(--font-serif);
  font-size: 13px;
  letter-spacing: 3px;
  color: var(--text-faint);  /* future */
  /* active/revealed 時 color: --text-primary / --text-secondary */
}
```

## 五、轉場與動畫

### 5.1 Cell 狀態變化

```css
.cell {
  transition: background-color 250ms ease-out,
              border-color 250ms ease-out;
}
```

任何 state 切換用這個 transition。不要加 transform / scale 動畫。

### 5.2 對話收尾轉場（完整時序）

```
T+0ms     AI 發出收尾訊息
          → 訊息 fade-in：opacity 0→1, 300ms ease-out

T+1500ms  Input box exit
          → opacity 1→0 + transform translateY(0→8px)
            duration: 250ms ease-out

T+1700ms  「✦ 教練在寫今天的字」 appears
          → fade-in: opacity 0→1, 400ms ease-out

T+1700ms — T+4500ms  Hold（約 2.8 秒）
          無動畫

T+4500ms  整個 conversation view fade out
          → opacity 1→0 + transform translateY(0→-12px)
            duration 400ms ease-in

T+4900ms  教練筆記頁 fade in
          → opacity 0→1 + transform translateY(8px→0)
            duration 500ms ease-out
```

### 5.3 筆記讀完 → 選擇按鈕觸發

```
用戶按下按鈕：
T+0ms     按鈕 active state（opacity 0.7），duration 100ms
T+100ms   整頁 fade out 250ms
T+350ms   新頁 fade in 250ms
T+600ms   complete
```

### 5.4 禁用的動畫

| 不要做                    | 原因                                           |
| ------------------------- | ---------------------------------------------- |
| Typing indicator dots (...) | 把對話變成 chat app                            |
| Loading spinners          | 破壞「教練在寫」的儀式感                        |
| Pulse / glow / shimmer    | active 邊框 + ✦ 已經夠了                        |
| Confetti / celebration    | 結業是私事，不是公開慶祝                        |
| Sound effects             | 整個產品是視覺 + 文字，無聲音設計                |
| Scale / bounce            | 太活潑，不符紙感氣質                            |
| Auto-scroll               | 學員應該掌控自己的閱讀節奏                      |

## 六、互動規則（**違反任何一條會破壞產品**）

### 對話介面

- ❌ NO quick reply buttons
- ❌ NO autocomplete in input
- ❌ NO predefined placeholder examples（e.g.「例如：我想要自由⋯」）
- ❌ NO suggested replies
- ❌ NO 「正在輸入...」 dots
- ❌ NO timestamps
- ❌ NO read receipts
- ❌ NO visible "Send" button (Enter 送出，Shift+Enter 換行)
- ✅ Input field auto-focus on conversation open
- ✅ Multi-line input wraps automatically

### 你的旅程

- ❌ NO completion percentage（「3/21 完成」）
- ❌ NO streak counter
- ❌ NO progress bar
- ❌ NO badges / achievements
- ❌ NO 「Day N locked」 overlays（future cells 只是淡淡地存在）
- ✅ Revealed cells 可點（重讀那天的筆記）
- ✅ Future cells 不可互動（但仍視覺存在）
- ✅ Active cell（今天）可點，進入對話

### Note / 週報 / 結業

- ❌ NO 「Save」 button (自動儲存)
- ❌ NO 「Share」 / 「Copy」 / 「Screenshot」 / 「Download」 buttons
- ❌ NO social media integrations
- ✅ 學員想分享自己截圖，產品不主動製造「向外展示」的衝動

### 對話結束

- ❌ NO 「End session」 / 「結束今天」 學員按鈕
- ✅ AI 主動判斷收尾，發送收尾訊息後輸入框退場
- ✅ 學員可以隨時關閉 App，但 App 自身不提供結束鍵

### 個人化稱呼

- ❌ NO 「歡迎回來，[user name]！」 這類問候
- ❌ NO 「您」 vs 「你」 切換 — 全部用「你」（親密、不商業）
- ❌ NO email 名字 / 帳號 / 個人資料顯示在 UI 上

### 錯誤狀態（重要）

- ❌ NO 紅色錯誤 banner
- ❌ NO 「網路錯誤！請重試」 alarm 風格訊息
- ✅ 使用同色系（米色 / 棕色 / 霧綠）來呈現所有 system feedback
- ✅ 錯誤訊息用宋體、平靜措辭：例如「沒能送出，我們再試一次」

## 七、響應式注意事項

### 桌面 (≥ 1024px)
- 使用本文件全部規格

### 平板 (768–1024px)
- max-width containers 維持
- 字級維持
- 8-col grid 維持

### 手機 (< 768px)
- **8-col grid 必須重新設計**（在 320–375px 寬螢幕上 8 個 column 會擠到無法閱讀）
- Cell 尺寸需放大以符合 44×44px touch target
- 對話容器寬度自適應 viewport
- 注意鍵盤打開時 layout shift（input 不能被遮住）
- **詳細手機版規格另行設計**

### Touch Target

## 八、Accessibility

- 文字最小對比度遵循 WCAG AA（faint future cells 為非互動性元件可豁免）
- 所有可點擊 cell 提供 aria-label：「第 N 天，[狀態]，[內容]」
  - 例：「第 3 天，已揭開，可以決定」
  - 例：「第 7 天，今天，點開進入對話」
- 螢幕閱讀器跳過裝飾性 ✦（`aria-hidden="true"`）
- 鍵盤導航：Tab 跑可互動 cell（active + revealed），Enter / Space 觸發
- Focus state：cell focus 加 `2px solid var(--border-active)` outline，inset
- 結業頁的宣言加 `<blockquote>` 語意

## 九、常見錯誤示警

下面這些是新進工程師 / 設計師最容易犯的錯誤，做 code review 時請特別注意：

| 錯誤                                         | 為什麼不行                                              | 正確做法                                                          |
| -------------------------------------------- | ------------------------------------------------------- | ----------------------------------------------------------------- |
| 「Loading...」「Generating...」「處理中...」 | 破壞「教練在寫」的儀式感                                | 用「教練在寫今天的字」這類人類化措辭                              |
| 顯眼的「Send」「Submit」按鈕                  | 把對話變成 form 提交                                    | 用 Enter 送出，可選擇加 ⏎ icon 提示但不要 button                  |
| 「歡迎回來，Sarah！」                         | 把產品從紙感打回 SaaS                                   | 完全省略 greeting，學員打開就直接看到「你的旅程」                  |
| 「您的進度」「您的成就」                      | RPG 化措辭                                              | 不出現「進度」「成就」這類字眼                                    |
| 紅色錯誤訊息                                  | 打破暖色平靜                                            | 用米棕色錯誤訊息 + 平靜措辭                                       |
| 「Day 4 (Locked)」 提示                       | future cells 不是「鎖住的」，是「還沒到的」              | 只用淡淡的 outline + 灰色 day number 表現                         |
| 自動 scroll 到對話最新訊息                    | 剝奪學員自己掌控節奏的權力                              | 學員自己 scroll；可以 highlight 新訊息但不要強制 scroll          |
| Hover state 用陰影或縮放                      | 破壞紙感                                                | Hover 用 border-color 細微深化（e.g. `--border-active`）          |
| 黑色文字 `#000`                               | 太硬，破壞暖色基調                                      | 用 `--text-primary` (#2C2825)                                     |
| 純白背景 `#FFF`                               | 太冷，紙感消失                                          | 用 `--bg-primary` (#FAF7F2)                                       |
