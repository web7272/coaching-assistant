# v5.0 Day 21 深度報告 spec（交付物 8）⭐ 學員帶走的 PDF

**作者**：Patrick ｜ 2026-05-23
**用途**：定義 21 天結束時、寄到學員 email 的「看見自己 · 深度報告」PDF——結構、視覺、生成方式、資料來源。
**前置**：交付物 1-7 + Vivi 5/23 拍板（emailed PDF / 稱「你」/ 5 章 / 純文字紙感 / app 輕暖 vs PDF 深收藏）
**參考**：Damon Cart 10 堂課深度報告架構（Vivi 提供）——本檔是它的 v5.0 5-Phase 改寫版。

---

## 0. 定位（一句話）

> 深度報告 = 學員 21 天走完、寄到 email 的 PDF。**重、深、收藏用**。
> 跟 app 上的「每日筆記 / 週報 / 結業」分工：**app 是當下被感受的體驗（輕、暖、紙感）；PDF 是帶回家的深度 artifact**。兩者不重複。

- **Day 21 = 結業頁（本身即第三週 + 全程收束）+ 深度 PDF 寄信箱**。不另出 week-3 週報頁。
- → 影響 07 §3-B/§3-C/§3-E：finalize-day 的 isWeekBoundary 對 Day 21 不再生「學員週報」、改生「結業 + 深度報告」；journey 的 Week III cell 點擊 → 開結業頁（不是空週報）。Claude Code 落地時對齊。

## 2. 深度報告結構（5 章、對映 5 Phase、全程稱「你」）

**標題**：看見自己 · 21 天深度報告
**副標**：從「{初始限制}」到「{確信身份}」——你如何擴大了自己的地圖

### 導言 · 轉化總覽
你來的時候（Day 1 表層目標 / 痛苦 + 原本用意志力或向外求驗證的無效策略）→ 21 天後的你（自然展現的品質、不是裝的、是證據重組後的確信）。

### 第一章 · 剝開表象，找到最高價值觀（Phase 1）
剝開表面故事、用「擁有這個對你有什麼重要」鏈式追問 → 你被挖出的核心價值觀 + 用 Containment Judgment（存在依賴測試）排出最具涵蓋力的 Top 1 → Phase 2 身份測試「你是一個『{Top1}』的人嗎?」當時的**模糊感**——點出這個模糊就是痛苦的根源。

### 第二章 · 你的「確信地圖」長什麼樣（取代 submodality）⭐ 改寫處
找到一個你**早已深信不疑**的品質、理解你「怎麼知道它是真的」——不是靠想像畫面，是靠**一連串具體生活事件**堆出來的證據地圖。洞見：大腦靠「證據的累積與結構」判定真假。這張既有的確信地圖，是接下來要把目標品質搬進去的模具。

### 第三章 · 擴大地圖：把目標品質鍛成不可撼動的身份（Phase 3a/3b + Scope Overlap + Cascade Down）⭐ 核心引擎
微證據收集（過去展現過目標品質的微小瞬間、數量本身成為質量）→ 跨越搬移（把證據放進確信地圖、用具體場景不調畫面）→ **Scope Overlap / 三向歸類**（把最強品質的證據範圍擴大、包覆其他面向）= 「擴大地圖 = 身份蛻變」的引擎。

### 第四章 · 核心戰役：反例整合與阻力收編（Phase 3b 反例整合）
直面最糟的反例（抽離、不陷情緒）→ 揭露阻力背後是「還在執行舊命令的部分」在保護你（不用敵意標籤）→ 帶著缺失的資源重新理解那個情境（具體場景重構 + 三向歸類、非 submodality 電影剪輯/魔鬼氈；深創傷即停轉真人）。為什麼最關鍵：沒有反例整合身份會脆弱又自戀；整合後面對挫折能迅速觸發卓越回應。

### 第五章 · 未來步調與放手（Phase 5）
建立未來記憶（3-5 個場景、抽離視角、細節模糊、保留彈性與動力）→ 一致性驗證「你現在是一個『{目標品質}』的人嗎?」→ 放手（NLP Amnesia：不需每天複習，讓新結構滑入潛意識自動運作）。

### 結論 · 臣服與自動化的卓越
從「對抗現實、逼自己」→「理解自己的內部地圖」。核心價值觀安裝成不可撼動的身份後，不再需要外部驗證。「你無法不成為你所深信的自己。」

### 附錄 · 你的 21 句話
daily_takeaways 那 21 句你自己的話（詩排版）。
⏳ 個人教練 prompt 先**不放**（Vivi 5/23、之後再議交付方式）。

## 3. 跟 Damon 參考架構的關鍵改寫（忠於 v5.0 方法論）

1. **次感官元解碼 → 擴大地圖 / Scope（具體場景）**：參考的「畫面位置 / 彩色黑白 / 關聯抽離」submodality 路徑、我們不用（亞洲適配、紅線 14、errata B）。改用具體生活事件構成的證據地圖。對齊副標「擴大地圖之旅」。
2. **魔鬼氈 / 重構資源電影 → 反例整合（具體場景 + 三向歸類）**：Re-imprinting 我們偵測 + 路由、MVP 不硬做；深創傷即停 handoff（紅線 20）。
3. **Cascade Down / 包覆 = 主引擎（第三章）**：在我們模型比參考更核心——這是 Vivi「挖出最強品質、包覆其他品質」的原創 IP。

## 4. 視覺：純文字紙感 PDF（5/23 拍板）

跟 app 同一套美學（UI 規格 §1/§2），**像一封長信 / 一本小冊、不是企業報告**：

- 背景 `--bg-primary #FAF7F2` / 紙卡 `--bg-card #FFFBF4`
- 宋體 `Noto Serif TC` 全程；章名 serif + letter-spacing；內文 serif ~16px lh 1.95（同 §4.6/4.7）
- 大量留白、章與章之間呼吸感；✦ 霧綠唯一 accent
- 署名「— 教練」
- **禁止**：圖表、數據表、bullet 海、螢光色、SaaS/報告感排版。引用學員原話用引號、不列點。
- 生成路徑：Sonnet 產結構化內容 → 紙感 HTML（重用 app design tokens）→ HTML-to-PDF。

## 5. 生成方式

```
觸發：Day 21 finalize（結業內容生成後）
1. 撈 21 天資料（§6）
2. Sonnet call：吃資料 + 本檔 §2 結構 + §7 紅線 → 產出 warm 第二人稱 5 章 markdown
3. 渲染成紙感 HTML（§4）→ HTML-to-PDF
4. Brevo email 寄給學員（附件 PDF）
   ⚠️ 依賴真 Brevo（PR-4c-2 目前 stub）——email 交付要等 Brevo 接上（Patrick 整合）。報告生成 + PDF 可先做、寄送後補。
```

| 第五章 | Phase 5 future pacing 場景、congruence check |
| 結論 | top1_value + 整體弧線 |
| 附錄 | daily_takeaways（21 句）|

> 來源 = 21 天每日完整 Damon Note（含所有結構欄位）+ user_profile_evolution。生成 prompt **讀完整版做素材、但輸出只寫暖敘事**。

## 7. 紅線 / student-safe（生成 prompt 守則）

- 全程第二人稱「你」+ 稱呼（preferredName）、不用「她/他」、不假設性別。
- **輸出絕不出現**：【SC 觀察】/ Layer N / 工具N / 採集追蹤 / 任何臨床鷹架（這些是教練版內部用、學員報告不露）。過 sanitizeStudentNote 當防護網。
- 守 Damon 紅線：不問「為什麼」、不肯定句/假裝、不 submodality 畫面身體（除非學員自發用）、阻力用「還在執行舊命令的部分」、深創傷不寫細節、不誇大療效。
- 用學員**原話**（引號）、不替他總結改寫他的話。
- 不誇大療效、不寫「跟著做就會好」。
