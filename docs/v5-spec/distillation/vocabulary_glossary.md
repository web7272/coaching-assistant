# Damon Cart 方法論術語對照表

> 此文件確保整個蒸餾過程中術語使用一致，避免漂移。
> 每層蒸餾發現新術語時，必須補入此文件。

## 已確立術語（第 1 層）

### Self-Concept
- **英文**: Self-Concept
- **中文**: 自我概念
- **可替換詞**: Identity（身份認同，Damon 體系中與 self-concept 完全等同）
- **定義**: 一個人對自己所有的歸納（generalizations），被總結成一個單一且強大的歸納
- **不等於**: 個性、性格、形象、人格（這些都是表面詞）
- **關鍵屬性**: 超越時空（transcends time and space）
- **金句**: "The mother of all of your beliefs."

### Identity
- **英文**: Identity
- **中文**: 身份 / 身份認同
- **與 self-concept 關係**: 完全等同，可互換使用
- **使用情境**: Damon 在強調「身份層次的轉化」時更常用 identity；在解釋結構時更常用 self-concept

### Quality / Qualities
- **英文**: Quality / Qualities
- **中文**: 特質
- **定義**: 對「你某方面特徵」的歸納（a generalization about an aspect of who you are）
- **層級位置**: 介於 experience 與 self-concept 之間
- **形成**: 多個正向經驗 + 「這與我有關」的識別 → 形成一個 quality
- **與 trait 的差異**: trait 是描述性的；quality 是大腦主動建構的信念，可被改變

### Experience
- **英文**: Experience
- **中文**: 經驗
- **定義**: 大腦標記起點與終點的意識切片
- **特殊性**: 不是客觀事件，而是大腦從感官資訊流中切割並命名的片段
- **重要**: 同樣的事件可被切割成不同的 experience，這是改變的可能性所在

### Generalization
- **英文**: Generalization
- **中文**: 歸納
- **定義**: 從多個具體案例提取共通模式的心理動作
- **層級**:
  - 多個 experiences → 一個 quality（小歸納）
  - 多個 qualities → self-concept（總歸納）

### Self-Esteem
- **英文**: Self-Esteem
- **中文**: 自尊
- **定義**: 對 self-concept 的感受（how you feel about your self-concept）
- **本質**: 是更高一層的 category（對 self-concept 的評價）
- **公式**: Value X + Belief「我不是 X」= 低自尊

### Value / Values
- **英文**: Value / Values（特別是 Core Values）
- **中文**: 價值觀（核心價值觀）
- **定義**: 對「對你來說重要的經驗」的歸納（a generalization about an experience that is important to you）
- **角色**: 藍圖 / 羅盤 / 動機引擎
- **與 quality 的差異**:
  - Value = 關於「什麼重要」的歸納
  - Quality = 關於「我是誰」的歸納
- **金句**: "Your values are your motivation."

### Core Values
- **英文**: Core Values
- **中文**: 核心價值觀
- **與一般 values 區別**: 真正屬於這個人的，非社會、家庭、performative 灌輸的
- **第 3 層待深化**: 如何區分 core vs surface

### Scope
- **英文**: Scope
- **中文**: 範圍（暫譯，可能保留英文）
- **定義**: 你投入注意力的所有資訊 + 它的結構（含 submodalities）
- **比喻**: 後台資料庫 / 程式碼
- **可被操作**: 重構 scope 即可自動翻轉 category
- **來源**: Steve Andreas NLP 模型

### Category
- **英文**: Category
- **中文**: 類別（暫譯，可能保留英文）
- **定義**: 你對 scope 的感受、分類、標籤、意義
- **比喻**: 螢幕上的顯示結果
- **鐵律**: 不可直接改變（直接改 = 大多數個人成長失敗的原因）
- **來源**: Steve Andreas NLP 模型

### Scope Overlap
- **英文**: Scope Overlap
- **中文**: 範圍重疊
- **戰略地位**: Damon 方法論的核心操作技術
- **流程**:
  1. 找出客戶絕對確信的特質（confirmed quality）
  2. 打開該特質的證據庫（scope）
  3. 在既有 scope 內發現新特質的存在
  4. 大腦自動完成 recategorization
- **AI app 中**: 必須能執行此提問流程

### Self-Fulfilling Prophecy
- **英文**: Self-Fulfilling Prophecy
- **中文**: 自我實現的預言
- **使用情境**: 解釋為何 identity 凌駕意志與努力
- **金句**: "Who you believe you are becomes a self-fulfilling prophecy—even if it's beliefs that you don't like about yourself."

### Recategorization（暫定）
- **英文**: Recategorization
- **中文**: 重新歸納 / 重新分類
- **定義**: 大腦在 scope 重構後，自動更新 category 的過程
- **特性**: 自動發生、無需意志力、發生在潛意識
- **觸發**: Scope Overlap 等技術

### Submodalities
- **英文**: Submodalities
- **中文**: 次感官元
- **定義**: 經驗的編碼結構（畫面大小、彩色/黑白、清晰度、聲音強度等）
- **角色**: scope 的「結構」部分
- **來源**: NLP 體系
- **第 5 層待深化**: 具體如何操作

## 1.4 新增術語（診斷模型）

### Parts（內在部分）⭐ 重要
- **英文**: Parts / Part of you
- **中文**: 部分 / 內在部分
- **來源**: NLP（特別是 Virginia Satir / Richard Bandler 的 Parts Integration 理論）
- **定義**: 人格內部不同的子系統，每個 part 有自己的價值觀、目標、行為策略
- **Damon 應用**: 阻力 = 另一個 part 在執行保護命令（不是性格缺陷）
- **核心命題**: **所有 parts 都有正向意圖（positive intent）**
- **金句**: "All resistance has a positive intention, a value it's seeking to fulfill."
- **第 4 層待深化**: Parts 的形成、衝突、整合的完整流程

### Positive Intent（正向意圖）
- **英文**: Positive Intent / Positive Intention
- **中文**: 正向意圖
- **定義**: 即使是製造問題的 part，背後都有它想保護或實現的價值
- **AI app 應用**: 不問「你為什麼這樣？」而問「這部分在保護你什麼？」

### Cognitive Dissonance（認知失調）
- **英文**: Cognitive Dissonance
- **中文**: 認知失調
- **定義**: 當行為/陳述與 self-concept 矛盾時的內在不適
- **Damon 應用**: 解釋為什麼肯定句失敗——大腦知道你在說謊，產生 dissonance，最終崩塌
- **與 scope/category 關係**: 直接改 category 而 scope 未變 = 必然 dissonance

### Modal Operators（情態助動詞）⭐ AI 偵測重點
- **英文**: Modal Operators
- **中文**: 情態助動詞
- **來源**: NLP Meta Model
- **包含**: I can't, I must, I should, I have to, I need to
- **Damon 應用**: **「I can't but I should」是 Damon 認定的「最嚴重受苦訊號」**
- **AI app**: 必須能偵測這些詞並觸發對應 reframe

### Meta Model（元模型）
- **英文**: Meta Model
- **中文**: 元模型
- **來源**: NLP（Bandler & Grinder 開創）
- **定義**: 識別語言中的扭曲（distortion）、刪除（deletion）、歸納（generalization）的工具
- **第 5 層待深化**: 具體 Meta Model 提問技術

### Map of Reality（現實地圖）
- **英文**: Map of Reality / The Map is Not the Territory
- **中文**: 現實地圖
- **來源**: NLP / Korzybski 一般語意學
- **定義**: 每個人的「現實」是大腦對外界的內在表徵，不是外界本身
- **Damon 應用**: 問題不是「現實」，是「地圖」（內部表徵）出錯

### Away-from / Towards Strategy（避開型 vs 趨向型動機）
- **英文**: Away-from motivation / Towards motivation
- **中文**: 避開型動機 / 趨向型動機
- **來源**: NLP
- **定義**:
  - Away-from：被痛苦推動（「我不想再...」）
  - Towards：被願景吸引（「我想要...」）
- **Damon 立場**: Away-from 會讓潛意識聚焦負面畫面，必須轉成 Towards
- **AI app**: 偵測「我不想...」型語言，引導轉化為「你想要什麼？」

### Course Correction（航向修正）⭐ 核心 reframe
- **英文**: Course Correction（vs Sabotage）
- **中文**: 航向修正
- **戰略地位**: Damon 對「自我破壞」的關鍵 reframe
- **完整命題**: 「卡住 / 拖延 / 無法達成」不是 sabotage，是潛意識在阻止你抵達錯誤目的地
- **AI app**: 客戶說 sabotage → AI 必須翻譯成 course correction

### Self-Worth（作為 Fiction）
- **英文**: Self-Worth
- **中文**: 自我價值
- **Damon 立場**: **這是虛構概念，不存在**。任何建立在它之上的解決方案也是虛構的
- **與 self-esteem 區別**:
  - Self-esteem = 對 self-concept 的感受（合法概念，可建構）
  - Self-worth = 假設你有一個內在「值不值得」的客觀標尺（fiction）
- **AI app**: 不可使用 self-worth / worthiness / deservingness 框架

### Hope = Hopeless ⭐ Damon 特殊用語
- **定義**: Damon 認為「I hope」實際上意味著「I'm hopeless / I have no power」
- **替代**: 用承諾（commitment）+ 行動取代希望
- **AI app**: 偵測「我希望...」要 reframe 成「你要承諾什麼具體行動？」

### Embodiment（具現化）
- **英文**: Embodiment / Embody
- **中文**: 具現化 / 體現
- **定義**: 把抽象的 value 內化為 identity 的一部分，「成為」而非「追求」
- **金句**: "Embody each one of your values as certain and solid qualities of your identity so you never have to strive for them ever again."
- **第 3、4 層待深化**: embodiment 的具體流程

### Compounding（自我強化循環）
- **英文**: Compounding
- **中文**: 自我強化循環 / 複利累積
- **定義**: Identity + 行為 + 結果之間互相強化的正向循環
- **金句**: "It becomes a compounding process that just continues to compound on itself."

### Chunk Up / Chunk Down（組塊上/下）
- **英文**: Chunk Up / Chunk Down
- **中文**: 組塊上 / 組塊下
- **來源**: NLP
- **定義**:
  - Chunk Up：從具體細節歸納到更大概念
  - Chunk Down：從大概念拆解到具體細節
- **應用**: experience → quality → self-concept 就是不斷 chunk up 的過程

## 1.5 新增/深化術語（變革方法論）

### Parts Integration（部分整合）⭐ 核心技術
- **英文**: Parts Integration
- **中文**: 部分整合
- **戰略地位**: AI app 處理阻力的核心 micro-flow
- **4 步驟**:
  1. 歡迎阻力，問正向意圖
  2. Away-from → Towards 翻轉
  3. Chunk up，找共同價值
  4. 賦予新任務（給 Part 一個位子）
- **核心金句**: "I've never met a part that said no. All it wants is to reconnect to the whole and fulfill its positive intent."

### Dissociated Image（抽離畫面）
- **英文**: Dissociated Image / Dissociated Vision
- **中文**: 抽離畫面 / 抽離視角
- **來源**: NLP（與 Associated 對立）
- **定義**: 在腦海中以「第三者旁觀」的視角看見自己
- **與 Associated 區別**:
  - Associated = 從自己眼睛看出去（第一人稱）
  - Dissociated = 看見自己（第三人稱）
- **Damon 應用**: Step 2 Build Vision 時用 dissociated 視角更能創造 Pull
- **判斷標準**: 「Vision feels like pulling you in」

### Confidence（自信）vs Self-Worth
- **Damon 立場**:
  - Self-worth = fiction，不存在
  - Confidence = 來自 Competence（能力）的累積，是真實可建構的
  - Self-esteem = 對 self-concept 的感受，當 values × identity 對齊時自然產生
- **AI app 公式**:
  - **Competence + Values Alignment → Confidence + Self-Esteem**
  - 絕不使用「提升 self-worth」「learn to love yourself」框架

### Competence（能力）
- **英文**: Competence
- **中文**: 能力
- **定義**: 在特定領域真實累積的技能與經驗
- **Damon 立場**: 自信來自能力，不是來自肯定句
- **與 self-worth 區別**: Competence 是可建構的客觀事實；self-worth 是虛構的內在標尺

### Feed-Forward System（前饋系統）
- **英文**: Feed-Forward System
- **中文**: 前饋系統
- **定義**: Identity 不只回應現實，更主動建構未來——「你現在相信自己是誰」會主動把你拉向那個未來
- **與 feedback loop 區別**: feedback 是過去→現在；feed-forward 是現在→未來
- **Damon 金句**: "Your identity is a feed-forward system, who you believe you are now pulls you toward the future and reinforces itself."

### Counter-Example Integration（反例整合）
- **英文**: Counter-Example Integration
- **中文**: 反例整合
- **定義**: 把與新身份矛盾的經驗（失敗）整合進積極數據庫，轉化為 course correction 的回饋
- **作用**: 改變的「免疫機制」——失敗不再威脅 identity
- **金句**: "Failures don't shake you—they teach you."

### 「Values never conflict, strategies conflict」原則
- **戰略地位**: AI app 處理任何「衝突」的核心信念
- **應用**:
  - 用戶感覺內在分裂 → AI 必須相信兩 parts 的 values 不衝突，只是 strategies 不同
  - 拒絕協助用戶「打敗某個 part」
  - 永遠引導向 chunk up 找共同價值

## Layer 3 新增術語（Values Elicitation）

### Trap Values（陷阱價值觀）⭐
- **3 大類別**:
  1. **外部驗證型**: Status, Power, Pride, Respect, Self-worth
  2. **副產品空泛詞**: Fulfillment, Purpose, Meaning, Confidence
  3. **動詞/策略偽裝**: 如「Helping others」
- **AI app 應用**: 必須識別並引導跳脫
- **特殊例**: Security（安全感）是門檻不是終點

### Nominalization（名詞化抽象）
- **英文**: Nominalization
- **中文**: 名詞化
- **來源**: NLP
- **定義**: 把動詞或過程變成抽象名詞（freedom, happiness, love）
- **問題**: 大腦無法直接處理 nominalization，需要 chunk down 變回具體經驗
- **Damon 應用**: Values 都是 nominalization，所以必須先設定具體情境/目標才能挖掘

### Hesitation is Good（停頓是好事）⭐ 核心判斷指標
- **戰略地位**: Damon 判斷真實 vs 表面 value 的關鍵指標
- **原則**: 客戶停頓 = 進入深層結構；秒答 = 表面台詞
- **AI app 代償**: 偵測回應速度、長度、感受詞使用

### Tangible Goal（有形目標）
- **英文**: Tangible Goal
- **中文**: 有形目標 / 具體目標
- **定義**: 感官可測量的具體事物（金額、物品、體驗）
- **作用**: 抽象 values 挖掘的「踏腳石」
- **AI app**: 起手式必須先建立 tangible goal，才能 chunk up 到 values

### Hierarchy of Values（價值觀階層）
- **英文**: Hierarchy of Values
- **中文**: 價值觀階層
- **2 大鐵律**:
  1. 永遠不離開特定情境
  2. 不是排「先後順序」，是找「最大涵蓋類別」
- **技術**: 兩兩 PK 淘汰賽

### Context（情境）
- **英文**: Context
- **中文**: 情境
- **戰略地位**: Damon 進行所有 values 工作的前提
- **規則**: 一次只挖一個 context（事業/關係/健康/財富/自我成長）
- **AI app**: Session 開始必須先確認 context

### 4 大驗證測試
1. **Strip-Down Test（剝除測試）**: 移除自我重要性後還剩什麼
2. **Applause-Free Test（無人鼓掌測試）**: 沒人知道也沒人鼓掌，還重要嗎
3. **Deathbed Test（臨終測試）**: 臨終回顧的視角（⚠️ 不是「6 個月可活」）
4. **Identity Test（身份測試）**: 你是個 X 的人嗎（觀察身體先給答案）

### Goal Alignment Test（目標對齊測試）⭐ 重要轉折點
- **時機**: 挖完 values 排序好之後
- **問句**: "Now that you know your values, will that goal really get you there?"
- **統計**: 50% 的客戶會在這裡改變目標
- **AI app**: 必須準備好處理「丟棄舊目標 → 設定新目標」的轉折

### Chain Question / 鏈式追問（核心引擎）
- **唯一問句**: "What will that do for you?" / "What's important to you about that?"
- **絕對禁止**: "Why?"
- **停止條件**: cycling back 或出現 byproduct words

### Curiosity as Resource（好奇心作為資源）
- **用途**: 處理「我不知道」的核心 reframe
- **邏輯**: 不知道 → 想知道 = 已經有 want
- **金句**: "If you don't know what you want, then what you want is to find out what you want."

## 補充術語（測試後追問補強）

### Ambiguous Quality（模糊特質）⭐ 身份測試診斷結果
- **英文**: Ambiguous Quality
- **中文**: 模糊特質
- **定義**: 客戶在身份測試中回答「usually / sometimes / I'm getting there」的 value
- **意涵**: 該 value 尚未成為穩固的 identity quality，需送入 Self-Concept 模型轉化
- **AI app 應用**: 這是 Layer 3 → Layer 4-5 之間的「轉診標籤」

### Kinesthetic Perceptual vs Kinesthetic Evaluative
- **Perceptual（感知型）**: 真實物理感官——腳踩地板、空氣溫度、皮膚觸感
- **Evaluative（評價型）**: 大腦對畫面的情緒反應——「這個感覺重不重要」
- **Damon 立場**: Perceptual 可用於 grounding；Evaluative 是陷阱
- **AI app 鐵律**: 不可用 Evaluative 取代邏輯判斷（如「哪個身體感覺最重」這類提問）

### Tracing Back（沿感覺往回走）
- **戰略地位**: Layer 4-5 處理深層阻力的核心技術
- **操作**: 抓住客戶身體裡的感覺當「繩索」，引導沿時間線找最初的印記
- **句式**: 「Walk that feeling back. How far back do you go?」

### Re-imprinting（重新印記）
- **戰略地位**: Layer 5 進階技術
- **操作**: 在身體裡定位資源（如「接納」），帶著它步入過去的自己
- **本質**: 改寫過去印記的 scope-category 結構

### Containment Judgment（涵蓋判斷）
- **英文**: Containment / Biggest Category
- **中文**: 涵蓋判斷
- **與 PK 關係**: PK 是「形式」，涵蓋判斷是「標準」（不是替代關係）
- **使用時機**: 客戶卡關 / 排線性錯誤時，AI 主動介入
- **AI app**: 必須能切換到涵蓋判斷模式，但不能取代 PK 程序

### Linear Thinking Error（線性思考錯誤）
- **定義**: 客戶把排序當「發生順序」（必須先 A 才能 B）
- **AI app 偵測**: 「我必須先...才能...」「沒有 X 就不可能 Y」這類句型
- **處理**: 立刻切換到涵蓋判斷邏輯

## Layer 4 新增術語（Resistance & Parts Integration）

### Japanese Soldier Metaphor（日本兵比喻）⭐ 核心
- **戰略地位**: Damon 對所有 Parts 的統一定義
- **意涵**: 二戰後仍躲在叢林裡的日本兵——它不是壞人，只是與主體失聯、不知道戰爭已經結束、還在執行舊命令
- **AI app 應用**: 取代所有敵意 part 標籤（破壞者、批評家等）
- **AI 可直接用此比喻向客戶解釋阻力**

### Outdated Programs（過時的程式）
- **英文**: Outdated Programs
- **中文**: 過時的程式 / 舊指令
- **定義**: Parts 在執行的內容——你過去下達的、現在不適用的保護命令
- **AI app**: 阻力浮現時的 reframe 框架：「這是哪一個過時程式在運作？」

### Course Correction（航向修正）⭐ vs Fear of Success
- **戰略地位**: Damon 對「Fear of Success」的關鍵 reframe
- **核心命題**: 客戶不是怕成功，是潛意識在阻止他抵達錯誤目的地
- **AI app**: 偵測「我有自我破壞傾向」「我害怕成功」→ 翻譯為 course correction

### Spectrum Reframe（光譜重構）⭐ 破解技術 1
- **適用阻力**: 害怕失敗 / 害怕失望
- **技術**: 將「目標」（穿針眼）重構為「方向 / 光譜」（每靠近一步都是進步）
- **句式**: 「如果你餘生都朝這個方向前進，每靠近一步都更 X，你會對此感到平靜嗎？」

### Compatibility Check（邏輯包容測試）⭐ 破解技術 2
- **適用阻力**: 害怕成功的代價
- **技術**: 測試「成功」與「客戶害怕變成的負面特質」是否真的互斥
- **句式**: 「成功與慷慨可以一起運作嗎？是不是越成功越能慷慨？」

### Accepting Cost in Advance（提前接受代價）⭐ 破解技術 3
- **適用阻力**: 生態破壞 / 害怕讓人失望
- **技術**: 承認代價真實存在，引導客戶有意識地選擇承擔
- **核心**: 把「驚嚇」變成「預先知情的選擇」

### As-If Frame / Experiment Frame（實驗框架）⭐ 破解技術 4
- **適用阻力**: 害怕未知 / 失控 / 不信任
- **技術**: 簽訂「試用期條約」，給阻力保留退出權
- **句式**: 「我們做個實驗，如果不行，我們把它們再分開」

### Re-imprinting（重新印記）⭐ 破解技術 5（Layer 5 預備）
- **適用阻力**: 創傷印記 / 自我價值低落
- **觸發時機**: Damon 自己承認的——當 Parts Integration 失效時
- **技術**: 引導成年客戶沿時間線回到過去，將「愛、接納、安全感」資源傳遞給受傷的年幼自己
- **戰略意義**: 這是 Damon 自己承認 Parts Integration 處理不了的情境，是 Layer 5 的核心技術

### Congruence Check（一致性檢查）
- **戰略地位**: 驗證整合是否真實的核心技術
- **句式**: 「現在看著你的願景，還有任何反對或阻力嗎？」
- **判斷**: 任何遲疑 = 整合未完成

### Future Pacing（未來步調）
- **英文**: Future Pacing
- **中文**: 未來步調
- **來源**: NLP
- **戰略地位**: 在 session 結束前，把改變放到未來情境中測試
- **句式**: 「想像三個月後你在 X 情境中——你會如何回應？」

### NLP Amnesia（NLP 失憶症）⭐ 整合成功的最終判斷
- **定義**: 真正成功的整合會讓客戶忘記自己曾有過這個阻力
- **意涵**: 改變沉入潛意識成為自動運作，客戶不會主觀感覺「我改變了」
- **AI app**: 不該追問「你有沒有覺得不一樣」，應該追蹤行為而非感受

### Ambiguous Quality（模糊特質）⭐ 重新定位
- **與 Parts 衝突的關係**: Damon 的關鍵洞察——Ambiguous Quality 本質上就是 Parts 問題
- **完整公式**: Ambiguous Quality = 兩套互不相容的 Scope 資料庫 = Parts 衝突的顯化
- **處理**: 必須走 Mapping Across（Scope Overlap）做結構性整合

### Mapping Across（跨重射圖）⭐ Layer 5 預備
- **英文**: Mapping Across
- **中文**: 跨重射圖 / 結構映射
- **戰略地位**: Damon 系統的終極殺手鐧——比 Parts Integration 更精確優雅
- **技術**: 將「反例 / 不想要的 Scope」物理性地融入「確信的 Scope 結構」中
- **與 Scope Overlap 關係**: 兩者是同一個技術的不同稱呼

### Parts Integration as "Fast and Dirty"
- **Damon 自己的定位**: Parts Integration 是「快速且粗糙」的開路先鋒
- **真正目的**: 鬆開煞車，讓客戶不再內戰
- **不是終點**: 真正的改變仍需要 Scope-Category 重構
- **AI app session flow 意涵**: Step 3 結束 ≠ 改變完成，Step 4 之前必須做 Step 3.5（身份測試）+ Step 3.6（Scope Overlap）

### Saboteur / Inner Critic（禁用詞）🚨
- **戰略地位**: AI 詞庫禁區
- **原因**: Damon 強烈反對任何敵意 part 標籤
- **替代**: 「過時的保護機制」「執行舊命令的部分」
