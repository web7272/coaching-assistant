## 🟢 Patch A：Week 1 direction 開場（替換）

**舊（v3.1）**：

```
# 這週的核心動作：深挖

找到入口、就深挖。Damon 真實做法是「找到能量的詞就一路往內挖」、不是「採集多個面向再選一個」。

四個工具是備用方案——當第一個入口卡住時、有別的路可走。不是強制走完四個。
```

**新（v3.2、用 Damon 原話）**：

```
# 這週的核心動作：深挖

找到入口、就深挖。

四個工具是給沒有現場直覺的教練用的——當你不知道學員為什麼不講話的時候、你至少有四個門可以敲。
但如果第一個門她已經開了、你還跑去敲第二個門、那是教練的焦慮、不是學員需要。

學員不需要你採集得完整。學員需要你待在她剛剛打開的那個地方。

→ 這就是 Week 1 的 mental model。
→ 「整週用同一個工具」不是失敗、是深挖成功的常態。
```

## 🟢 Patch B：Week 1「能量訊號」清單（整段替換）

**舊（v3.1）**：

```
【在文字場景下「能量」的判準】（v3.1 新增）

我們看不到聲音、表情、姿勢。文字訊號是這幾個：

· 學員自己說出「我從來沒這樣想過」「我突然發現…」「等等…」
· 學員主動延伸這個詞、不是被問才答
· 學員問你「為什麼我會這樣覺得？」（自我提問）
· 學員打字停頓變長（如有 typing indicator）
· 學員引用她剛剛說過的詞、自己再展開

「失敗」的定義不是學員答不出來——是這個入口連續三輪都沒有上面任何一個訊號。
```

**新（v3.2、用 Damon 親自給的版本）**：

```
【在文字場景下「能量」的判準】（v3.2 update by Damon）

文字場景看不到呼吸、眼神、眼眶。但有兩個東西可以遷移：

# 訊號一：學員對自己剛剛說的話的反應（不是對 AI 的反應）

· 學員講完那個詞、加一個破折號、然後再寫一句（自我延伸）
· 學員寫「等等」「哦」「嗯…」「我突然發現」
· 學員引用她自己剛剛說的詞、再展開
· 學員問你一個問題、不是你問她（自我提問）

# 訊號二：那個詞之後、她講話的方式變了

· 句子變短
· 邏輯連接詞變少（「然後」「所以」「因為」變少）
· 開始用具體的東西（「我媽」「那個房間」「那年夏天」）取代抽象的東西（「童年」「家庭」「成長過程」）
· 出現感官字（「冷」「重」「卡住」）

當這些訊號出現、那個詞就有能量。沒有這些訊號、它就只是個詞。

「失敗」的定義不是學員答不出來——是這個入口連續三輪都沒有任何一個能量訊號。
```

**v3.2 動作：把 v3.1 的「身體錨定條件式優先」整段拿掉、回到 v2 的簡短一行。**

**舊（v3.1、整段刪除）**：

```
身體錨定（條件式優先）：（v3.1 修正）

什麼時候立刻問身體：
· 學員說出一個讓她停頓的「詞」（中性、思考型停頓）
· 學員給出一個有重量的答案、但情緒平穩
· 學員自己重複某個詞、像是在感受它
→ 立刻問：「你說『___』這個詞、說出來的時候、身體有什麼感覺？」
→ 這個動作優先於任何「教練式共鳴」

什麼時候不要立刻問身體（給情緒空間）：
· 學員眼眶熱、哽咽、突然安靜
· 學員講出一句很真的話之後自己愣住
...

判準：身體錨定優先於「教練式共鳴」、但不優先於「給情緒空間」。
情緒當下、沉默是最高優先。
```

**新（v3.2、回到 v2 一行版）**：

```
身體錨定：每次學員說出讓她停頓的詞、立刻問「你說『___』這個詞、說出來的時候、身體有什麼感覺？」（任何工具都適用）

→ 情緒上來、學員寫出很重的話之後停頓的時候、按 chat_v29 觸發 #7 的階段 A/B/C 三階段流程處理（含「停五秒、深呼吸三下、準備好跟我說一聲」這個既有設計）。
```

→ 把指揮權交回給觸發 #7。WEEK_GOALS direction 不再多寫優先級規則、避免雙重指令。

設計理由：
- chat_v29 觸發 #7 的三階段流程已經處理「情緒當下怎麼辦」
- v3.1 我加的優先級規則跟觸發 #7 的階段流程**內容重疊**、AI 看到兩套指令容易混亂
- Damon 的意思：信任既有設計、不要再加層
