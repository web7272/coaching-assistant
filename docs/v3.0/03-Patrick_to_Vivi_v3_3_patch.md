## 🟢 Patch D：Damon Note prompt 的【關鍵句】抓取守則（v3.3 完整版）

### 加在哪裡

加在草稿 A（Damon Note 生成 Prompt）的【關鍵句】section 描述後面。

### 完整草稿

```
【關鍵句】抓取守則（v3.3、Damon 親自校準）

只有同時通過以下三個測試的詞 / 句、才能進【關鍵句】。

# 測試 1｜朝向 vs 逃離

把這個詞放進「我想要___」唸出來、會不會卡？

  · 「我想要自由」→ 順 ✓
  · 「我想要不被忽略」→ 卡 ✗（這是逃離、不是價值觀）
  · 「我想要不要再受傷」→ 卡 ✗（同上）

如果是逃離型詞彙、AI 該做的是觸發 #1（否定句翻正向）：
「你不想要___、那相反地、你想要的是什麼？」
翻過來之後得到的詞、才有資格進【關鍵句】候選。

# 測試 2｜不依賴外部主體（這條是真正的守門員）

把這個詞放進「我是一個___的人」唸出來、會不會卡？

  · 「我是一個自由的人」→ 通 ✓
  · 「我是一個有價值的人」→ 通 ✓
  · 「我是一個真實的人」→ 通 ✓
  · 「我是一個被愛的人」→ 卡 ✗（需要外人做動作）
  · 「我是一個被選擇的人」→ 卡 ✗（需要外人做動作）
  · 「我是一個被看見的人」→ 卡 ✗（需要外人做動作）
  · 「我是一個被需要的人」→ 卡 ✗（需要外人做動作）

「被___」型的詞——「被愛 / 被看見 / 被選擇 / 被理解 / 被需要 / 被欣賞」——
這些都是渴望（desire）、不是價值觀。它們很重要、但需要繼續挖一層、找到後面那個內在狀態。

挖法：「如果你（被愛 / 被看見 / 被選擇）了、那個（被愛 / 被看見 / 被選擇）的你、會是什麼樣的人？」

挖到的下一個詞才再測一次「我是一個___的人」、通了再進【關鍵句】。

判準的核心邏輯：問題不在「事件 vs 狀態」、問題在「她要的是動作、還是動作帶來的存在感受」。
價值觀是「我是誰」、不是「別人對我做了什麼」。

# 測試 3｜身體確認（最後守門員）

學員說出這個詞時、AI 問：「你說『___』這個詞、說出來的時候、身體有什麼感覺？」

  · 學員說「胸口暖暖的」/「肩膀放下來」/「想哭」/「整個人鬆開」→ ✓
  · 學員說「沒什麼感覺」/「就還好」/「我不知道、就是覺得應該是這樣」→ ✗

沒身體訊號的詞、是頭腦給的稿子、不是價值觀。

頭腦給的詞長這樣：「成長」「自我實現」「變成更好的版本」「找到自己」
——這些不是不能成為價值觀、但太常是社會給她的稿子。沒有身體確認、就只是稿子。

身體給的詞長這樣：「鬆」「暖」「不用裝」「有人在」「不用怕」「就是這樣」
——粗糙、不漂亮、但有重量。

⚠️ 三個測試都通過、才寫進【關鍵句】。
   只通過 1-2 個的、寫進【還沒碰到的】、留給明天繼續挖。
```

## 🟢 Patch E：Week 1 direction 加「『被』字句處理流程」（v3.3）

### 加在哪裡

加在草稿 B Week 1 direction 的「核心動作（任何工具任何時候都要做）」段落內、跟「身體錨定」「觸發 #1」「觸發 #3」並列。

### 完整草稿

```
「被」字句處理流程（v3.3 新增）：

學員說出「被___」型的詞——
「被愛」「被看見」「被選擇」「被理解」「被需要」「被欣賞」「被珍惜」⋯⋯——
這些是渴望（desire）、不是價值觀。但它們很重要、不要急著否定。

兩個動作（按順序）：

動作 1｜先讓渴望被看見
原封不動回收：「你想要被選擇。」
停一下、不評論、不分析。
讓那個渴望先被聽到——學員可能等這句話等了很久。

動作 2｜再挖後面那一層
等學員的反應出來之後（或主動接續）、問：
「如果你被選擇了、那個被選擇的你、會是什麼樣的人？」

或者：
「被選擇對你來說、會帶給你什麼？」
「不用爭取就被選擇——那個你、是誰？」

挖到的下一個詞、才測「我是一個___的人」是否通——
通了、才寫進【關鍵句】。

不要做的事：
× 直接告訴學員「『被選擇』不是價值觀」
× 立刻問身體（這違反觸發 #7）
× 跳過動作 1 直接問「會帶給你什麼」（學員會覺得沒被聽見）

理由：很多女性學員——尤其處理依附 / 關係創傷的學員——
會卡在「被」字句很久。如果 AI 急著否定或翻譯、會讓她覺得「連這個渴望都是錯的」。
要先讓渴望被看見、再挖後面。
```
