## 🎯 Damon 回覆的關鍵 reasoning（要寫進 v4 文件的 metadata）

### 1️⃣ L3 + 觸發 #3 順序

```
L1 行為 → L2 情緒 → L3 Scope&Generalization → L4 價值觀 → L5 身份
                                              ↑
                                    觸發 #3 在這裡才啟動
```

- 觸發 #3（「為什麼這對你來說很重要？」）= 純粹 chunk up、L3 之**後**才用
- **2A 池本身已經在 L4-L5、所以 2A confirm 後接觸發 #3 仍適用、不用插 L3 過渡**
- **例外（必須寫進 v4）**：學員回答觸發 #3 時掉回 L2（如「就覺得很難過啊」「就是很在乎啊」）→ 插 L3 過渡「這種感覺應該不只發生過一次。最近有沒有兩三個讓你有同樣感受的情況？……退一步看、這些事情的共通點是什麼？」→ 共通點說出來後**才**回到觸發 #3

### 2️⃣ 2A confirm + Scope 證據要求（雙重錨定）

```
★ 穩定性測試（confirm 不動）：
  「這句話——不管誰問、什麼時候問、答案都一樣嗎？」

★ 證據要求（新增、v3.2b 沒有）：
  「好。你說你是一個___的人——把過去你做過、最能證明這點的一兩件
   具體的事情、說給我聽。」

★ 然後才進觸發 #3：
  「為什麼這對你來說很重要？」
```

**價值雙重**：
- 對 Week 1：確定感 + 證據庫雙重錨定、避免 Week 3 Transfer 崩塌
- 對 Week 3 Day 3：Week 1 採到的具體事件、就是 Day 3 打開 Scope 的素材庫、不用重採
- **Damon Note 要在【關鍵句】之外加一個【Scope 證據】欄位、記具體事件原文**

### 3️⃣ 2B 池分階段（Week 1 採集 ≠ Week 2 整合）

```
2B 池｜Reactive 池

Week 1 Day 3-4（採集版、停在第④步）：
  ① 「這個模式——它是想保護你什麼嗎？」
  ② 「它怕你失去什麼？」
  ③ 翻正向：「好、那它想要的是什麼？」
  ④ 連到 Week 1：「它想要保護的這個東西、有沒有在你說的那些詞裡？」
  ⑤ ⛔ 停在這裡。Week 1 不賦予新角色。

Week 2 Day 3（整合版、完整四步驟）：
  Step A 歡迎阻力 → Step B 翻正向 → Step C 確認相容性 → Step D 賦予新角色
  → 必須等學員打出「它答應了」「它說好」「它願意」
  → 卡點處理：「沒關係、它非常盡責。它還需要你保證什麼？」
```

**為什麼不能 Week 1 賦予新角色**：
1. 語錄還沒挖出來（Week 2 Day 1-2 工作）→ 還沒看見那個聲音背後是誰
2. 正向意圖還沒對齊到 Week 1 核心價值 → 沒有共享價值就是空頭支票
3. 打字錨定的儀式感會被稀釋 → 是 Week 2 崩潰落淚的時刻、Week 1 用會失去份量

### 4️⃣ 2C 池分階段（Week 2 對話弧線升級）

```
Week 2 對話弧線（升級版）：
  Day 1-2：聽見語錄 + 找來源（觸發 #6 Step 1+2）
  Day 3：賦予新角色（2B 完整四步驟移到這裡）★ 新增的過渡橋樑
  Day 4：反例提問（觸發 #6 Step 3「這句話永遠都是真的嗎？」）
  Day 5：反例的你 + 它也是你
  Day 6：第二版 SC + Week 3 鉤子
```

**為什麼順序這樣**：
- Day 3 賦予新角色 = 阻力承諾不再「扯後腿」→ 阻力卸下武器
- Day 4 反例提問 → 那個聲音已經不在防守狀態 → 學員可以真正看見反例

**Day 2 收尾守則**：學員若還沒清楚說出來源（「我不知道從哪來的」/「就是有這種感覺」）→ **不要強推 Day 3**、Day 2 多停一天、用「這句話如果有聲音、是誰的聲音？聲音從哪個方向來？」幫她找。沒有來源就賦予新角色、那個角色找不到對話對象。

**Step 3 原文也要對齊**：v3.2b 寫「Step3 在 Week 2 第 3-4 天做」→ 改成「**Step 1+2 在 Week 2 Day 1-2；Step 3 在 Week 2 Day 4、前提是 Day 3 已完成賦予新角色。**」

### 5️⃣ 三模組句式池增量（29 句、不是 25）

**自我模組** — 15 句 不動

**金錢模組** — +2 句：
- **2C 加**：「我是一個覺得想要更多會被說___的人」
  → 通常填：貪心、不知足、不滿足、自私
  → 命中「貪心語錄」入口、連到 Week 2 Day 2 貪心翻轉
- **2B 加**：「我是一個面對自己過得比父母好通常___的人」
  → 通常填：愧疚、不安、想隱藏、想低調、不敢說
  → 命中「對父母忠誠」入口、連到 Week 2 Day 2 後段

**關係模組** — +2 句：
- **2A 加**：「我是一個在關係裡通常___著對方的人」
  → 通常填：照顧、遷就、擔心、討好、配合
  → 是「被需要模式」入口（不是被看見）、連到 Week 1 Day 2 伏筆
- **2C 加**：「我是一個覺得自己有需要會___別人的人」
  → 通常填：麻煩、給負擔、拖累、增加困擾、佔用
  → 命中「需要=負擔」核心限制性信念

**守則**：句式 = 入口（釣餌）、核心問句 = 收線。句式池不要寫太完整、超過 7 句會選擇癱瘓、每池守 5-7 句之間。

### 6️⃣ 不新增 2D 池（底層邏輯）

| | 句式池（2A/2B/2C）| 確定類別（Week 3 Day 3）|
|---|---|---|
| 動作本質 | **採集**（廣度優先）| **篩選**（深度優先）|
| 目的 | 列出多元面向讓學員選 | 從學員生命裡篩出那一個 |
| 啟動腦區 | 比較與選擇（左腦選項處理）| 自我認同核心錨點（更深層歸納系統）|
| 守則 | 學員可以挑、可以猶豫 | **學員必須毫不猶豫** |

**底層**：句式池本質「**句式採集**」、確定類別本質「**身份篩選**」。不能放同一個籠子。如果做 2D 池等於「替學員選了選項」、違反 Week 3 Day 3 首要守則「永遠等學員自己說出那個詞」。

**Cathy v4 自我模組 Week 3 Day 3 已經對的**：

## 🔁 Patrick 對 spec 落地的兩個觀察

### 觀察 A：v4.0 spec §1 守則三需要加 explicit fallback rule

我之前 spec §1 守則三只寫「L3 主路徑 = Scope & Generalization」、但 Damon 校準點 1 揭示：**觸發 #3 鏈式追問期間、如果學員掉回 L2 → 必須插 L3 過渡再回觸發 #3**。

這個 fallback rule 要明確寫進 chat.js DAMON_CORE：
```
【觸發 #3 鏈式追問的 L3 fallback】
- 學員回答觸發 #3 時掉回 L2（純情緒、沒具體事件）
- → 插 L3 過渡：「這種感覺應該不只發生過一次。最近有沒有兩三個讓你有同樣感受的情況？……共通點是什麼？」
- → 共通點說出後、才回到觸發 #3 繼續往上問
- 反例（不要這樣）：學員給情緒 → AI 直接繼續「為什麼這對你很重要？」→ 變成空中情緒滑梯
```

### 觀察 B：v4.0 spec §8 Damon Note prompt 需要新欄位

Damon 校準點 2 揭示：2A confirm 後加 Scope 證據要求、目的之一是**Week 1 採到的具體事件給 Week 3 Day 3 打開 Scope 直接調用**。

Damon Note 需要新增欄位：
```
【Scope 證據】（Week 1 採集、Week 3 Day 3 調用）
記錄學員在 2A confirm + 觸發 #3 之間說出的具體事件原文。
格式：
- 確立特質：愛 / 毅力 / 負責任 / ... （學員自己說出的詞）
- 具體事件：
  事件 1：[原文]
  事件 2：[原文]
- 這些事件、Week 3 Day 3 直接調用、不用重採
```
