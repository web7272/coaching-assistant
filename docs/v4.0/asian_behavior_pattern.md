## 🎯 核心 thesis（一句話）

> **Damon 純正 SC 教練學的核心技術「次感官 + 空間位置」對亞洲人不適用、必須用 Vivi 提出的「Scope and Category」(Steve Andreas 理論) 取代、並把 L3 從「身體感覺」改成「證據庫提取與歸納」、這是 v4.0 教練學重組的根本。**

Damon 在解析 4 完全同意 Vivi 的觀察：

> 「東方文化傾向整體關聯性思考、不傾向把自我拆解成空間幾何碎塊」

## 📊 五個亞洲人行為模式相關洞見

### 1. 不傾向視覺化空間幾何思考

**現象**：傳統 NLP 要求「畫面在你個人空間的哪裡？左前方還是右後方？」對東方學員無效、會卡在理智層面的困惑

**解法**：用 Scope & Category（範圍與類別）取代空間位置
- 不需要搬動空間
- 用「擴大證據範圍 → 大腦自動完成歸納」
- 認知層面自動完成、避開視覺化抗拒

### 2. 不傾向身體拆解 / 但會列舉具體事件

**現象**：「茫然在身體哪裡？」「胸口有什麼感覺？」對東方學員引發抗拒（A001 Day 2-3 親測證實）

**解法**：L3 主路徑改成 **Scope & Generalization**（證據庫提取與歸納）
- 「這種感覺、應該不只發生過一次。最近有沒有兩三個讓你有同樣感受的情況？」
- 「退一步看——這些事情的共通點是什麼？」
- 列舉多個事件 → 大腦自動抽離（Disassociation）
- 找共通點 → 大腦站到後設位置（Meta Position）提煉意義

身體感覺降為**次要路徑**：學員自己說了身體詞（悶、緊、輕、空、重、卡住、熱、冷）才錨定、同對話最多一次、抵抗後退場

### 3. 行動派 / 努力派 / 責任驅動

**現象**：東方社會習慣靠努力達成目標、對「愛」「接納」感到抽象、但對「能吃苦、有毅力、值得信賴、負責任」深信不疑

**解法**：核心類別不限定「愛」一條路、列五種常見 anchor：
1. 接納 / 感恩（全包容、最高層次）
2. 好奇心（沒有評判、適合無法相信自己有勇氣的學員）
3. 毅力 / 堅持（東方行動派最強地基）
4. 同理心 / 善良 / 給予（關係驅動）
5. 值得信賴 / 負責任（東方文化最普遍、秒答）

**守則**：永遠等學員自己說出那個詞、不替學員選

### 4. 對「父母忠誠」的隱性束縛

**現象**：金錢模組會出現「讓自己過得不要太好、是一種對父母的忠誠」、關係模組「我的需要會造成負擔」這種繼承式自我限制

**解法**：金錢模組 Week 2 Day 2 加入「對父母的忠誠（金錢版）」問句：
- 「有沒有可能、你在金錢上讓自己不要太好、是一種對___的忠誠？如果你賺得比他們多、過得比他們輕鬆——那意味著什麼？」

### 5. 怨恨 / 指責 → 受害者狀態

**現象**：Week 2 語錄溯源時、東方學員容易陷入「都是他們的錯」的指責模式、宣告自己無能為力

**解法**：Week 2 Day 1-2 條件觸發「怨恨/指責卡點四步驟轉化」：
1. 停止指責、拿回情緒所有權
2. 挖掘怨恨背後的正向意圖
3. 從逃避翻轉為追求（Away-from → Toward）
4. 行為對齊、重新啟動

| 範疇 | v3（舊）| v4（新）| 影響面 |
|---|---|---|---|

| **身體錨定** | 主路徑、收窄限制二 | **次要路徑**、學員自己說身體詞才用、同對話最多一次 | hotfix 1/4 全 obsolete |
| **Week 3 Transfer** | （或無、或身體心錨確定感遷移）| **Scope/Category Transfer**（找確立類別 → 打開範圍 → Scope Overlap 三層 → Re-categorization）| WEEK_GOALS.self.3 / money.3 / relationship.3 全重寫 |

## 📋 對 v3.4 production code 的影響面

### chat.js 改動範圍（從大到小）

1. **DAMON_CORE 守則三整段重寫** — L3 主路徑變更
2. **WEEK_GOALS.self.1（Week 1）** — Day 1-6 加 L3 Scope & Generalization 問句
3. **WEEK_GOALS.self.2（Week 2）** — Day 3 新增「賦予新角色 + 文字 App 確認」、Day 1-2 加「怨恨/指責卡點」條件段
4. **WEEK_GOALS.self.3（Week 3）** — 全部重寫（從 v3 的內容變 v4 的 Scope/Category Transfer + 反例預演 + 宣言）
5. **WEEK_GOALS.money.1-3** — 同 self 全更新、加金錢特定段落（驕傲/羞愧雙束縛、薪水=自我價值、貪心翻轉、對父母忠誠）
6. **WEEK_GOALS.relationship.1-3** — 同 self 全更新、加關係特定段落（感情功能化、被需要 vs 被看見、需要作為負擔、付出動機）
7. **generateDamonNote prompt** — Damon Note 重點變更（記錄確定類別、Scope 證據、Transfer 評分、反例預演結果、宣言）
8. **buildSystemPrompt** — 視 Week 3 Day 3-4-5-6 邏輯、加 Scope/Category Transfer 階段檢查
9. **工具二 v3.2b 對齊** — 看是否需要新版

### 預估 prompt 體積變化

- v3.4 production：~12,500 tokens
- v4.0 全替換：估計 **+30-40%**（多了 Scope 路徑 + 反例預演 + 賦予新角色 + 怨恨卡點 + 五種類別參考 + 完整 Week 3 重組）
- 即 ~16,000-17,000 tokens
- **這是 Vercel Pro maxDuration 60s 邊界、需要評估**

### 工程觀察

- Anthropic Sonnet 4.6 處理 16K tokens system prompt + 3K conversation context = 18-20 秒
- Vercel Pro 60s 還容得下、但 buffer 變窄
- 可能需要做 prompt caching（穩定區塊 cache、動態區塊每次重發）
- 或評估某些大段落是否要 conditional inject（Week 1 對話時不需要 load Week 3 Day 4 的詳細 Transfer spec）
