共同框架
這份手冊三個模組共用以下核心框架。教練在進入任何模組之前，必須熟悉這一部分。
核心守則
→  不替學員說出任何一個詞。所有答案都繼續往下問，直到學員說出一個讓她停頓、或說出「共通點」的核心詞為止。
→  不評論學員的答案。聽懂了就繼續問，不是給建議。
→  阻力不是敵人。當阻力出現，歡迎它，問它的正向意圖，給它新任務。
→  第四週是整合週，不是新的挖掘。把三週素材帶進來，讓兩個 SC 說話，然後做 Transfer。
邏輯層次定義表（更新版）
▲ 升級版  L3 已從「身體感覺」更新為「證據庫提取與歸納（Scope & Generalization）」
L1  行為敘述
學員描述她做了什麼、發生了什麼事。她說的是外部世界的事。
L2  情緒
學員說出她感覺什麼——難過、焦慮、開心、失望。開始往內走。
L3  證據庫提取與歸納
（Scope & Generalization）
學員列舉多個類似情境，並說出它們的「共通點」。
這是從情緒走向價值觀的真正橋樑。

AI / 教練判斷指標：
學員說出一個不只一次發生的模式，或說出「每次都這樣」「一直是這樣」
→ 問：「這些情況的共通點是什麼？」
→ 讓她自己歸納出意義標籤（Category）。

📌 身體感覺只在學員自己先說了身體詞（悶、緊、輕、空）時才錨定，
不主動引導。身體感覺是 L3 的次要路徑，不是主路徑。
L4  價值觀 / 渴望
學員說出她真正在乎的——自由、被看見、真實、連結。身份層的入口。
L5  身份（Self Concept）
學員說出「我是誰」的句子，或對自己本質的判斷。整個框架的核心。
L3 核心問句（教練使用）
→  當學員的情緒（L2）說完之後，不要問「身體哪裡有感覺」，改問：
「這種感覺，應該不只發生過一次。最近有沒有兩三個讓你有同樣感受的情況？」
「退一步看——這些事情的共通點是什麼？」
📌 讓她自己說出共通點（例如：「每次都是為了讓別人高興」「每次都先想到別人才想到自己」）。那個共通點，就是 L3 的歸納結果，也是進入 L4 的門。
📌 要求列舉多個事件，大腦會自動抽離（Disassociation）；尋找共通點，大腦會自動站到後設位置（Meta Position）提煉意義。這樣完成的 L3，不依賴身體感覺，對亞洲學員完全適用。
SC Transfer 方法說明（Scope & Category 法）
▲ 升級版  第四週 Step 4 全面換用此方法，取代原本的「身體確定感遷移」
傳統做法要求學員找到確定感的畫面並搬動空間位置，對亞洲學員容易產生理智層面的障礙。
新方法用「範圍重疊（Scope Overlap）」，讓新身份的證據借用已確立身份的龐大證據庫，不需要搬動空間。
第一步｜找已確立的強大類別（Certain Category）
「在你的生命裡，有沒有哪個特質，是你『完全不懷疑』自己擁有的？
就算別人質疑，你也毫不動搖？（例如：愛、善良、負責任）」
→ 等學員說出來，不要替她舉例。
第二步｜打開這個類別的證據庫（Scope）
「當你說你是一個【有愛】的人，你是怎麼知道的？
把你過去做過最能證明這點的一兩件具體的事情，說給我聽。」
→ 讓學員充分說，教練記下這些具體事件。停在這個確定感裡。
第三步｜範圍重疊——三層問句（Scope Overlap）
★ 第一層（最直接）：
「在你付出愛的那些時刻——想一個最具體的畫面——那個時候，你做了什麼？」
→ 讓學員先說出具體行為，不要她自己判斷是不是「目標特質」。

★ 第二層（學員說「沒有」時的翻轉問句）：
「你做那件事的時候，有沒有任何一個細節是沒有人教你的？
是你自己摸索出來的、或者你自己決定要這樣做的？」
→ 用「沒有人教你」替代目標特質的名稱，讓大腦從另一個門進去。

★ 第三層（最終兜底，重構定義）：
「如果我們把【創造力】定義成——在沒有標準答案的情況下，找到一個最適合這個人的方式——
你覺得你做過嗎？」
→ 先改掉學員對目標特質的窄定義，再讓她看見自己的例子。

📌 教練守則：如果學員一直說「我不覺得我有」——問題不在她沒有，
而在她對目標特質的定義太窄。教練的工作是先幫她把定義打開，
她的例子自然就出來了。不要急著帶她進下一步。
第四步｜意義的重新歸納（Re-categorization）
「當你發現，原來你過去所有的【愛】裡面，都已經包藏著無數個【目標特質】的證據時——
現在，你對『我是一個____的人』這句話，相信程度從幾分變成了幾分？」
→ 不替她說。等她自己將擴大後的範圍，歸納成全新的身份認同。
第五步｜確定感測試
「帶著這個全新的發現——現在告訴我，關於你自己這個人，你是誰？你相信這句話幾分？」
→ 確定感遷移完成的標誌。
自我模組
主角｜曉琳
家族底層信念（第三週才浮出來）：
→  「三心二意不會成功」
→  「樣樣通樣樣不精」
→  「虎頭蛇尾」
→  「努力就會有結果，沒有結果就是你不夠好」
→  「你要讓人看見你的價值，不然沒有人在乎你」
曉琳的核心問題（她自己還不知道）：
不是熱情對不對，不是行動夠不夠。是她每一次行動，都不是從她真正是誰長出來的。有一半是為了證明「我不是三心二意的人」，另一半是怕如果不做，就什麼都不是。所以做再多，還是感覺空。
四週概覽
第 1 週｜價值觀挖掘
影片先，Session 後。影片裝框架，Session 讓框架進入學員自己的生命。
📌 核心守則：不從情緒進，從慾望進。「你想要什麼」是最誠實的入口。影片讓學員有了「地圖」和「邏輯層次」的語言框架，Session 才能讓他們用這個框架看見自己。
暖身｜建立探索語境
[0–10 分]  建立探索語境
→  「你看了這週的影片，有沒有什麼東西讓你停下來？」
📌 讓學員從影片素材進入 Session，不是從零開始。
→  「你說的那個讓你停下來的地方——在你自己的生活裡，它長什麼樣子？」
→  若學員沒有特別感受：若學員沒有特別感受：「你現在的生活裡，有什麼地方讓你感覺不對勁？」
第一層｜鏈式追問
[10–45 分]  鏈式追問
→  反覆用：「那對你意味著什麼？」或「擁有這個，對你有什麼重要？」
📌 Damon 的核心問句。每次學員回答之後，就用這兩句中的一句繼續往下。
→  停下來的訊號：學員說出某個詞時停頓、聲音變輕、重複說同一個詞——那個停頓就是入口。
📌 不要問「身體哪裡有感覺」。當學員說出有能量的詞，繼續鏈式追問，直到她說出單字級別的核心詞。
▲ 升級版  L3 橋樑問句（取代原來的「身體有感覺」）
→  當學員說出某個情緒或困擾，先問：
「這種感覺，應該不只發生過一次。最近有沒有兩三個讓你有同樣感受的情況？」
「退一步看——這些事情的共通點是什麼？」
📌 讓她自己說出共通點。那個共通點就是 L3，也是進入 L4 的門。
第二層｜★ 邏輯層次連結
[45–65 分]  邏輯層次連結（自我模組特有）
★ 「你說你一直在____（行動）。那個行動，它是在哪個層次上努力？是在改變你做的事，還是在改變你是誰？」
📌 把影片的「邏輯層次」概念直接連到學員的生命——這是自我模組第一週特有的問句。
★ 「你剛才說的這些你想要的——在你是誰這個層次上，那說明了什麼？」
📌 從行為層次帶到身份層次，為整個模組的 SC 工作做準備。
結尾｜清單＋預告
[65–75 分]  清單＋預告
→  「今天你說出來的這些詞，把它們寫下來，用你自己的語言，不修飾。」
→  預告下週：「下週我們要把每個詞的定義說清楚，再來排序。同樣的詞，不同的人說的完全不一樣。」
→  作業：「這週觀察一件事——你在什麼情況下感覺最像自己？不是最成功，是最像自己。記下來。」

第一週常見卡點
第 2 週｜定義確認＋排序＋願景建立
先讓學員定義每個詞，再排序。沒有定義就排序，等於在沙上建房子。
📌 核心守則：定義確認不能省略——同一個詞，不同學員的定義可能完全不同。
暖身｜清單回顧確認
[0–10 分]  清單回顧確認
→  「上週挖出的清單，這週看還有感覺嗎？有沒有哪個詞你想加或換掉？」
→  「上週作業——你在什麼情況下感覺最像自己？那個觀察，有沒有帶來什麼？」
定義確認
[10–25 分]  排序之前必做
→  逐一拿出清單上的每個詞，問：「你說的「___」，在你的生活裡長什麼樣子？如果你真的有了它，你的某一天是怎麼過的？」
📌 讓定義從學員自己的生命裡出來，不是字典的定義。
→  「這個定義，是你自己的，還是你以為它應該是這樣的？」
→  若學員說「應該是這樣的」：「那你自己的定義是什麼？不用正確，就是你的。」
價值觀排序
[25–40 分]  兩兩配對
→  「如果只能選一個，你選哪個？」兩兩配對，每次只問一對。
→  學員說「我都重要」：「我知道。但如果真的只能留一個，今天的你會選哪個？」
→  讓學員最難選的那一對——特別標記，第三週的材料。
願景建立（三層深化）
[40–58 分]  現場建立自我願景
→  「讓一個畫面自然浮現——你在其中，周圍有你剛才說的這些價值觀的某種感覺。那個你，是誰？」
→  保持沉默 2–3 分鐘，不打擾。然後問：「你看到什麼了？」
→  「現在有了這個願景，你覺得今天的你，距離它有多遠？1–10。」
📌 願景要模糊——不要引導學員想具體的職位或成就，是感受的狀態。
▲ 升級版  願景深化｜Gap Awareness（取代「Magnetic Pull 抽離式吸引力」）
★ 以下問句用於願景深化，當學員已說出新身份的輪廓後使用：
「那個已經完全活出新身份的你，今天早上醒來的第一個念頭是什麼？今天的你醒來的第一個念頭是什麼？」
「這個差距——說明了什麼？」
📌 不要求學員「看著前方那個自己」（視覺化空間），改用兩個狀態的「具體差距對比」。對比感知本身就會產生動力，完全不需要空間感。
願景深化問句（V1–V8 身份層）
V1  「你剛才說你是一個___的人。那個人，她現在在哪裡？她在做什麼？」
📌 讓身份先站穩，畫面從身份裡長出來
V2  「那個你，她今天早上起床的時候，第一個感覺是什麼？今天的你醒來的第一個感覺是什麼？說說這兩個的差距。」
📌 用日常細節讓願景具體化，同時帶入 Gap Awareness
V3  「那個你，她看待自己的方式，和今天的你有什麼不同？」
📌 用對比讓學員感受到移動的距離
V4  「那個你，她遇到壓力的時候，她的第一個反應是什麼？」
📌 把 SC 放進真實情境
V5  「那個你，她和身邊的人說話的方式，和今天的你有什麼不同？語速？音量？停頓？」
📌 從關係互動角度讓 SC 具體化
V6  「那個你，她最不需要向任何人證明的是什麼？」
📌 挖出 SC 裡的內在穩定感
V7  「那個你，她每天結束的時候，她感覺自己___。用一個句子說完。」
📌 讓學員用現在式描述那個身份的日常感受
V8  「那個你，如果要用三個字形容她是誰，她會說什麼？」
📌 教練記下來，第四週整合會用到
願景深化（T1–T3 時間軸落地）
T1  「那個未來的你，現在站在你旁邊。她看著今天的你，她想說什麼？」
📌 把未來的 SC 具體化成一個人
T2  「那個你，在一年後的某一天醒來，她看到的第一個東西是什麼？她的第一個念頭是什麼？」
📌 用具體的時間點讓願景落地
T3  「如果那個你回來告訴你，你現在需要先做的一件事是什麼，她會說什麼？」
📌 把願景連到現實行動
結尾｜願景錨定＋預告
[58–70 分]  願景錨定
→  「把你的願景用你自己的話寫下來，放在看得到的地方。」
→  「這週如果有什麼聲音說「但是…」——把那個聲音記下來，那是下週的材料。」
第二週常見卡點
第 3 週｜家族語錄信念辨識
從原生家庭的語錄找到阻力真正的根源。課前工作表帶進 Session 深入。
📌 核心守則：聽語氣和身體反應，不是聽內容。學員唸出那句語錄的時候，教練先不說任何話，只觀察。先問「那個不敢/不行的你認為自己是誰」，再問「你真正想要成為誰」。阻力背後的舊 SC 必須先被看見，新的才能站得住。
課前回顧
[0–10 分]  工作表帶進 Session
→  「你帶工作表來了嗎？我想請你翻到讓你停下來最久的那句話，唸出來給我聽。」
📌 聽語氣和停頓，不是聽內容。唸出那句話的時候，教練先不說任何話，只觀察。
步驟一｜家族語錄深入
[10–25 分]  家族語錄深入
→  「你寫下的那句家族語錄，你現在唸出來給我聽。」
→  「說這句話的人，他們自己活在這個信念裡嗎？他們快樂嗎？」
📌 讓學員看見語錄的來源者本身——有時候這個問句會讓學員第一次感到心疼而非憤怒。
→  「這句話，在你的生命裡，讓你做了哪些「安全」的選擇？那些選擇，是你真正想要的嗎？」
步驟二｜記憶盤點
[25–40 分]  記憶盤點
→  「那個記憶裡的你幾歲？你現在可以看到她嗎？」
→  「那個小孩當時沒有辦法說的話，是什麼？」
📌 讓壓抑的情緒有出口。
→  「那個小孩後來怎麼處理這件事？她學到了用什麼方式應對？」
📌 把童年結論連到現在的行為模式。
步驟三｜信念提煉
[40–52 分]  信念提煉
→  「你圈出來的那句話，你現在唸給我聽。」
→  「這句話是你自己說的，還是你在重複某個人說的？那個人是誰？」
★ 「這個信念——在你對自己的態度裡，有沒有同樣的影子？你怎麼評判自己每次「停下來」的那個選擇？那個聲音，是不是同一個根？」
📌 把家族語錄連到自我關係——這是自我模組最核心的連結。
步驟四｜現在信念檢視
[52–62 分]  現在信念檢視
→  「這個信念，今天的你還相信它嗎？」
→  「它現在還在保護你什麼？如果它消失了，你最擔心的是什麼？」
阻力的正向意圖＋賦予新角色
▲ 升級版  阻力工作新增「賦予新角色」步驟——這是讓學員真正整合阻力的關鍵時刻
→  「那個讓你停下來的聲音，你有沒有想過，它在試著為你做什麼？這個部分的你，是想保護你什麼嗎？」
★ 「它怕你失去什麼？好，那它真正想要的是什麼？不是它怕的，是它想要的。」
📌 把 away-from（遠離動機）翻轉成 toward（追求動機）。
→  「它想要保護的這個東西——有沒有在你第一週說出的那些詞裡？」
📌 把阻力和核心價值觀連在一起。學員通常會發現阻力和渴望其實在保護同一件事。
▲ 升級版  ↓ 以下為新增的「賦予新角色」步驟
★ 確認相容性：「所以那個讓你停下來的聲音，它其實是在保護你的【正向意圖】。這個意圖，和你想達成的目標衝突嗎？其實是一致的，對嗎？」
★ 賦予新角色：「現在，我想請你在心裡，給這個一直想保護你的部分下一個新任務。問問它——在你未來勇敢嘗試新事物時，它願不願意成為你的『真實雷達』，隨時提醒你保持初心，而不是用「放棄」來拉手煞車？……問問它，它答應了嗎？」
📌 等學員真的在心裡問完，並說出「它答應了」或「它說好」。不要跳過這個步驟。當學員說出這幾個字，大腦的神經整合才正式完成。這通常是整個第三週讓學員感動落淚的瞬間。
SC 橋樑
[62–70 分]  Self Concept 連接
→  「那個繼承了這個信念的你，認為自己是一個什麼樣的人？她允許自己有什麼、不允許自己有什麼？」
→  「那個選擇更新這個信念的你，是一個什麼樣的人？她和自己的關係是什麼樣的？」
📌 這是整個第三週最重要的一句話，要從學員嘴裡說出來。
第三週常見卡點
第 4 週｜SC 整合與歸位
兩個 SC 對話完成，Transfer 落地，當場安裝新身份。90 分鐘完成。
📌 核心守則：第四週是整合週，不是新的挖掘。教練在暖身時把三週的素材整理好，步驟二直接用。這週最重要的時刻是讓兩個 SC 說話——不是消滅舊的，是讓兩個都被看見。
暖身｜三週回顧＋素材確認
[0–10 分]  三週回顧
→  「今天是第四週。把三週的工作表翻出來——第一週的落地問句、第二週的願景 V8、第三週的新信念。」
→  「這三週，你對自己最大的一個發現是什麼？」讓學員自己說，教練記下關鍵詞。
📌 教練記下三個素材：① 第一週落地問句的答案 ② 第二週 V8 ③ 第三週新信念方向，步驟二直接用。
步驟一｜從評分切入，找到卡住的地方
[0–12 分]  評分接續
「上週你說你相信新的那個你___分。今天這個分數有沒有變化？」
📌 從第三週的評分接續——不是從頭開始，是繼續走。
「那個讓它還沒到10的地方，是什麼？那個聲音說你是一個什麼樣的人？」
📌 讓舊的 SC 自然浮出。
「這個聲音，你認識它嗎？它從第幾週開始就在了？在家族語錄裡，它叫什麼？」
📌 把舊的 SC 連回三週的工作脈絡。
步驟二｜整合三週素材，說出新的 Self Concept
[12–25 分]  整合
📌 教練在這步驟前，先把三週的素材唸給學員聽：第一週，你說你是「___」；第二週，那個願景裡的你，V8 是「___」；第三週，更新之後你是「___的人」。
「把這三個放在一起——今天，你是誰？用一句話。現在式。」
📌 給很長的沉默，等她自己說。這一步說出的才是三週工作的真正結晶。
「這句話，和第一週你說的那句比，哪裡不一樣？哪裡更像你？」
「這個新的你，你相信她幾分？1–10。」
📌 確認新的 SC 的真實程度，這個分數是步驟五微證據掃描的基準。
步驟三｜兩個 Self Concept 直接對話
[25–38 分]  兩個 SC 對話
「步驟一那個說你___分的聲音——讓它問現在這個新的你一個問題。它最想問的是什麼？」
📌 通常是：「你憑什麼認為你可以？」或「你只是在騙自己。」
「讓新的那個你回答。不是你努力想出一個答案，是讓那個你從她自己的位置說話。」
📌 教練不干預，不引導。如果學員卡住，只說：「讓那個新的你說話。她知道答案。」
「那個舊的聲音，聽到這個回答之後，它還有什麼要說嗎？」
📌 讓對話完整。
步驟四｜Self Concept Transfer（Scope & Category 法）
▲ 升級版  本步驟全面更新——取代原本「身體確定感遷移」，改用 Scope & Category 範圍重疊法
[38–58 分]  Self Concept Transfer
→  找已確立的強大類別：
「在你的生命裡，有沒有哪個特質，是你「完全不懷疑」自己擁有的？就算別人質疑，你也毫不動搖？」
📌 等學員說出來，不要替她舉例。常見回答：愛、善良、負責任、認真、對朋友的義氣。
→  打開證據庫（Scope）：
「當你說你是一個【___】的人，你是怎麼知道的？把你過去做過最能證明這點的一兩件具體的事情，說給我聽。」
📌 讓她充分說。教練記下這些具體事件。停在這個確定感裡。
★ 範圍重疊——三層問句（Scope Overlap）：
📌 第一層（直接問）：
「在你展現【確立特質】的那些時刻——你說你一直覺得自己不夠____（目標特質）——但在那些時刻裡，你是如何「順便」或「必須」動用了____的能力？」
📌 第二層（學員說「沒有」時）：
「你做那件事的時候，有沒有任何一個細節是沒有人教你的？是你自己摸索出來的？」
📌 第三層（最終兜底）：
「如果我們把【目標特質】定義成——在沒有標準答案的情況下，找到一個最適合這個人的方式——你覺得你做過嗎？」
📌 教練守則：如果學員一直說「我不覺得我有」，問題不在她沒有，而在她對目標特質的定義太窄。先幫她把定義打開，她的例子自然就出來了。
→  意義重新歸納（Re-categorization）：
「當你發現，原來你過去所有的【確立特質】裡面，都已經包藏著無數個【目標特質】的證據時——現在，你對「我是一個____的人」這句話，相信程度從幾分變成了幾分？」
📌 不替她說。等她自己將擴大後的範圍，歸納成全新的身份認同。
→  確定感測試：
「帶著這個全新的發現——現在告訴我，關於你自己這個人，你是誰？你相信這句話幾分？」
Transfer 後｜時間軸鋪展
▲ 升級版  新增——在 Transfer 完成後，把確定感沿時間軸穩固下來
[58–65 分]  時間軸鋪展
★ Transfer 完成後，立刻接這個問句：
「如果這個新身份的確定感有一種顏色（或一種聲音），把它從現在這一刻開始，沿著你的未來往前鋪展——一年、五年、十年。當你的未來都被這個確定感包覆，你的身體現在感覺到了什麼？」
📌 不要要求學員「看到畫面」——用「感覺到」不用「看到」。對亞洲學員更自然。這個問句是在神經層面為未來「鋪路」，產生深層的平靜與確定感，消除對未來的焦慮。
步驟五｜微證據掃描
[65–75 分]  微證據掃描
「在過去三週，有沒有任何一個瞬間，哪怕只有 1%，你已經活在那個新的你裡面了？」
「還有嗎？」
📌 每找到一個，只說「還有嗎？」不評論，不讚美，只收集。找到三個以上。
「這些瞬間，說明了什麼？你現在相信那個新的你幾分？1–10。」
📌 與步驟二的分數對比。
微證據掃描後｜反例預演（身份免疫）
▲ 升級版  新增——幫學員為未來的挫折安裝免疫機制
[75–82 分]  反例預演
★ 微證據掃描完成後，接這個問句：
「想像未來某一天，你遇到了和過去一模一樣的挫折，或者有人否定了你。看著那個新的你——她是帶著什麼樣的資源與姿態去回應這個挫折，而且絲毫不懷疑她自己的價值？」
📌 讓學員描述那個新身份如何面對挫折。一個真正穩固的 SC，不是完美的，而是能整合反例的。這個問句強迫大腦進行一次神經預演，讓學員看見新身份在面對阻力時依然穩固。未來的挫折就只是純粹的反饋，不再是自我貶低的開端。
步驟六｜新的 Self Concept 說話
[82–90 分]  宣言
「如果新的那個你，現在可以說一句話給三週前剛開始的你聽，她會說什麼？」
📌 給充分的沉默。
「你現在是誰？」
📌 最後一個問句。簡短，直接。教練只說：「我聽到了。」這是整個四週最重要的時刻。
宣言格式
→  「我是一個___的人。我不需要用___來___，因為我本來就___。」
示範（曉琳型）：「我是一個正在學習相信自己的人。我不需要用「拼命行動」來「證明我不是三心二意」，因為我本來就有資格停下來，從自己身上找方向。」
📌 示範只是參考方向，不要唸給學員聽。讓學員用自己的語言說出來——那句話是她的，不是你的。沉默等她說，教練只說「我聽到了」。
每天練習三步驟公式（完成四週後）
→  步驟一｜翻譯：把那個讓你覺得「不夠好」的自我標籤，翻譯成中性或正向的能力描述。
→  步驟二｜植入：根據你最看重的價值觀，選一個讓你有力量的形容詞，說出新的身份句。
→  步驟三｜掃描：接下來 24 小時，找 1% 符合新身份的行為，腦中按讚存檔。
三個月後，回來看第一週說的那些詞，和今天說的這句話——那個距離，就是你走過的路。
金錢事業模組
主角｜淑芬
家族語錄（第三週才浮出來）：
→  「穩定最重要，不要亂跑」
→  「沒有資格失敗」
→  「做人不能太出風頭」
→  「有錢不要讓人知道，會被針對」
→  「你這樣已經很好了，不要貪心」
淑芬的底層真相：
她說她要的是「穩定」。但穩定不是她的價值觀，是她的保護殼。她真正在保護的，是這件事——如果她嘗試了、失敗了，那個「有能力、有價值、可以被需要」的身份就會被戳破。她的雙重束縛：想要更多（驕傲）又怕被看見（羞愧）。所以她待在原地。十三年了。
四週概覽
第 1 週｜金錢＋事業價值觀挖掘
影片先裝框架——你在金錢和事業上，在哪個邏輯層次上努力？
📌 核心守則：金錢事業模組第一週同時挖兩個面向——金錢和事業。底層是同一個問題：「我值得嗎？我夠好嗎？」從這個底層問句進去，不從外部成果進去。
暖身
[0–10 分]  建立探索語境
→  「在你的金錢和事業上，有什麼地方讓你感覺不對勁？或者有什麼地方，你覺得應該不是這樣的？」
第一層｜金錢價值觀挖掘
[10–35 分]  金錢面
→  起點問句：「在金錢上，你真正想要的是什麼？第一個冒出來的。」
→  反覆用：「那對你意味著什麼？」或「擁有這個，對你有什麼重要？」
★ ★ 剝離外部認同：「如果你已經賺到了你渴望的那個數字，但沒有任何人知道，也沒有人會鼓掌——這筆錢對你來說，還剩下什麼重要性？」
📌 如果她瞬間失去動力，代表她在用金錢證明自己——這是整個模組最核心的發現。
→  若學員說「我只是想要穩定」：「那個穩定，是你真正想要的，還是你最不能失去的？這兩個，有什麼不一樣？」
▲ 升級版  L3 橋樑問句（取代原來的「身體有感覺」）
→  當學員情緒出來後，改問：
「這種焦慮感（或這個不對勁），應該不只發生過一次。在金錢或事業上，最近有沒有兩三個讓你有同樣感受的情況？」
「退一步看——這些情況的共通點是什麼？」
📌 讓她自己說出共通點，就是進入 L4 的門。
第二層｜事業價值觀挖掘
[35–58 分]  事業面
→  起點問句：「在事業上，你真正想要的是什麼？不是職位，不是薪水——是那個讓你覺得值得的東西。」
★ ★ 邏輯層次連結：「你說你一直在____（努力、負責、穩定）。那個行動，是在改變你做的事，還是在改變你是誰？」
★ ★ 驕傲與羞愧的雙重束縛：「你說你想要更多——那個背後，有沒有一部分是希望別人看見你有能力？另一部分，有沒有是怕失敗了別人怎麼看你？」
第三層｜★ 自我價值觀察（伏筆）
[58–65 分]  伏筆種下
★ 「你剛才說的這些——你現在給自己這些東西嗎？你允許自己有這些嗎？」
📌 種下伏筆：金錢事業的缺口，往往是自我價值的缺口在外部的投影。
第一週常見卡點
第 2 週｜成功定義覺察＋定義確認＋排序＋願景
這週最核心的轉折：你現在用什麼定義成功？那個標準，是你選的，還是你繼承來的？
成功定義覺察
[0–20 分]  排序之前必做
→  「你現在主要是用什麼標準定義自己在金錢和事業上的成功？」
★ 「那個標準，是你選的，還是你繼承來的？」
📌 這是整個金錢事業模組最核心的轉折點。給學員足夠的空間感受這個發現。
→  「如果把所有外部的指標都拿掉，你還覺得自己成功嗎？」
★ ★ 驕傲與羞愧：「你追求金錢和事業成功，有多少是因為你真的渴望那個狀態，有多少是因為怕被別人看不起？」
定義確認＋排序
[20–48 分]  定義→排序
→  逐一拿出清單上的每個詞，問：「你說的「___」，在你的金錢和事業生活裡長什麼樣子？」
→  「如果只能選一個，你選哪個？」兩兩配對，每次只問一對。
★ ★ 若學員把「安全感」或「穩定」排第一：「那個安全感被滿足之後，你真正渴望的是什麼？在金錢這個情境下，有沒有一個更讓你感覺活著的東西？」
📌 安全感是保護性的低階需求——滿足後無法帶來真正的成就感。引導她往上一層找高階價值觀（自由、貢獻、創造）。
願景建立
[48–68 分]  三層願景深化
→  「帶著你的排序，讓一個畫面浮現——在那個金錢和事業都對的狀態裡，你是誰？」沉默 2 分鐘。
★ ★ V6 特別重要：「那個你，她最不需要向任何人證明的是什麼？」
📌 讓學員感受到「不需要證明」的感覺，往往是她這輩子第一次。
▲ 升級版  願景深化｜Gap Awareness（取代「Magnetic Pull 抽離式吸引力」）
★ 以下問句用於願景深化，當學員已說出新身份的輪廓後使用：
「那個已經完全活出新身份的你，今天早上醒來的第一個念頭是什麼？今天的你醒來的第一個念頭是什麼？」
「這個差距——說明了什麼？」
📌 不要求學員「看著前方那個自己」（視覺化空間），改用兩個狀態的「具體差距對比」。對比感知本身就會產生動力，完全不需要空間感。
第 3 週｜家族語錄信念辨識（金錢事業版）
從原生家庭的語錄找到金錢和事業阻力真正的根源。
步驟一｜家族語錄深入
[10–25 分]  家族語錄深入
→  「你小時候，家裡常常聽到的一句話是什麼？關於金錢、成功、努力——挑一個說。」
→  「那句話，現在用你的聲音唸出來給我聽。」
→  「說這句話的人——他們自己活在這個信念裡嗎？在金錢上，他們是豐盛的嗎？他們快樂嗎？」
📌 金錢模組特有：加入「在金錢上豐盛嗎」這個追問，讓學員直接看見信念來源者和金錢的真實關係。

★ Transfer 完成後，立刻接這個問句：

★ 微證據掃描完成後，接這個問句：

📌 讓學員描述那個新身份如何面對挫折。一個真正穩固的 SC，不是完美的，而是能整合反例的。這個問句強迫大腦進行一次神經預演，讓學員看見新身份在面對阻力時依然穩固。未來的挫折就只是純粹的反饋，不再是自我貶低的開端。

四週概覽
第 1 週｜關係價值觀挖掘
影片先裝框架——你在關係裡，在哪個邏輯層次上努力？
📌 核心守則：關係模組第一週的入口和自我、金錢事業不同——不從「你想要什麼」進，從「你感覺不對勁的是什麼」進。學員說不清楚，不代表沒有問題，代表那個問題還沒有被允許浮出來。
暖身
[0–10 分]  建立探索語境
→  「在你最重要的關係裡，有什麼地方讓你感覺不對勁？或者有一種說不上來的感覺——把那個感覺說出來，不用整理，不用合理。」
→  若學員說「我說不清楚」：「那個說不清楚的感覺，先讓它說話。它是什麼溫度？什麼重量？」
→  若學員說「我們關係其實還好」：「還好裡面，有沒有一點點說不上來的不滿？或者有什麼地方，你覺得可以更好？」
★ ★ 感情功能化問句：「你們最後一次只是聊天——沒有談事情、沒有談孩子、沒有談家務——是什麼時候？」
📌 這個問句讓學員第一次看見感情已經功能化了多久。通常讓學員第一次真正停下來。
▲ 升級版  L3 橋樑問句（關係版）
→  當學員說出某個委屈或焦慮，改問：
「這種感覺，應該不只在這段關係裡發生過。在你的生命裡——家庭、友情、工作關係——最近有沒有兩三個讓你有同樣感受的情況？」
「退一步看——這些情況的共通點是什麼？」
📌 讓她自己說出共通點。那個共通點通常是「我的需要被忽略了」或「我一直在照顧別人的感受」。那就是進入 L4 的門。
第一層｜關係困境切入
[10–40 分]  六個層次的關係困境
→  從學員說的入口往下問：「那個讓你感覺不對勁的，最具體的是什麼情境？」
★ ★ 情緒支持缺失：「當你說「我今天真的很累」，你希望對方的回應是什麼？你得到的是什麼？那個差距，讓你感覺什麼？」
★ 「在這段關係裡，你上一次感覺自己被看見——不是被需要，是被看見——是什麼時候？」
📌 被需要和被看見的差異是整個關係模組最核心的問題。今天種下伏筆，第二週深挖。
第二層｜關係渴望挖掘
[40–65 分]  需要覺察
★ ★ 核心問句：「在這段關係裡，你需要什麼？不是你希望他做什麼——是你，你需要什麼？」
📌 很多學員第一次被問到這個會愣住，因為她從來沒有被允許這樣問自己。問完就停，給充分的沉默。
→  「你說你需要___。你有沒有讓對方知道？你有沒有讓自己知道？」
★ ★ 需要作為負擔：「你說你需要___——那個需要，會造成別人的負擔嗎？」
📌 直接碰觸惠茹型學員最核心的限制性信念。不評判，讓它說話。

依附模式覺察
[0–25 分]  慣性還是選擇？
★ 「你在關係裡一直在付出——你知道為什麼嗎？那個付出，是愛，還是你以為這樣才能被留下？」

★ Transfer 完成後，立刻接這個問句：
「如果這個新身份的確定感有一種顏色（或一種聲音），把它從現在這一刻開始，沿著你的未來往前鋪展——一年、五年、十年。當你的未來都被這個確定感包覆，你的身體現在感覺到了什麼？」
📌 不要要求學員「看到畫面」——用「感覺到」不用「看到」。對亞洲學員更自然。這個問句是在神經層面為未來「鋪路」，產生深層的平靜與確定感，消除對未來的焦慮。

「在過去三週，有沒有任何一個瞬間，哪怕只有 1%，你已經在關係裡更完整地是自己了？哪怕只是一個你選擇說出來的話、或一個你讓自己被看見的念頭——」
「還有嗎？」
微證據掃描後｜反例預演（身份免疫）
▲ 升級版  新增——幫學員為未來的挫折安裝免疫機制
[75–82 分]  反例預演
★ 微證據掃描完成後，接這個問句：
「想像未來某一天，你遇到了和過去一模一樣的挫折，或者有人否定了你。看著那個新的你——她是帶著什麼樣的資源與姿態去回應這個挫折，而且絲毫不懷疑她自己的價值？」
📌 讓學員描述那個新身份如何面對挫折。一個真正穩固的 SC，不是完美的，而是能整合反例的。這個問句強迫大腦進行一次神經預演，讓學員看見新身份在面對阻力時依然穩固。未來的挫折就只是純粹的反饋，不再是自我貶低的開端。
步驟六｜宣言
[82–90 分]  宣言
「在這段最重要的關係裡，你現在是誰？」
📌 最後一個問句。簡短，直接。教練只說：「我聽到了。」這是整個四週最重要的時刻。
宣言格式（關係模組）
示範一（惠茹型）：「我是一個值得被看見的人。我不需要用「不斷付出」來「換取被留在這段關係裡的資格」，因為我本來就值得被愛——不是因為我有用，而是因為我是我。」
示範二（忍一忍版）：「我是一個有資格說出需要的人。我不需要用「忍一忍」來「證明我是個好妻子」，因為我本來就可以在關係裡也是自己。」
每天練習三步驟公式（關係模組版）
→  步驟一｜翻譯：把那個讓你把需要藏起來的衝動，翻譯成它真正在保護的是什麼——然後問：那個保護，今天還需要嗎？
→  步驟二｜植入：根據你最看重的關係價值觀，說出一句「在這段關係裡，我是___的人」。
→  步驟三｜掃描：接下來 24 小時，找 1% 你在關係裡完整是自己的瞬間——哪怕只是一個你選擇說出來的話——腦中按讚存檔。

五種核心類別參考表（Scope & Category Transfer 輔助工具）
▲ 新增  新增——幫助教練有方向感，但絕對不替學員選詞
★ 首要守則：永遠等學員說出那個詞。如果你覺得他適合用「愛」，但他對愛帶有條件性的懷疑，重疊就會失敗。只要學員說出那個詞時具備毫不猶豫的確定感，那就是最好的核心類別。

▲ 新增  新增——反例預演三個 NLP 結構原則 + 完整四步驟腳本（逆境免疫文件）
僅預演成功是致命盲點：如果只預演成功，當學員在現實中遇到第一個挫折時，剛建立好的新身份就會因為缺乏「應對失敗的藍圖」而瞬間崩塌。強大的 SC 必須能夠包容並整合反例。
三個 NLP 結構原則（引導前必須遵守）：
1. 必須是「抽離的（Disassociated）」
絕對不能讓學員「進入」那個未來的失敗場景去體驗痛苦。必須讓她像看電影一樣，看著前方那個「新的自己」去處理問題。抽離的視角能保護學員不被情緒淹沒。
2. 細節必須是「極度模糊的（Vague）」
未來還沒發生，我們不知道具體會出現什麼挑戰。如果設定得太具體（例如：看見老闆在會議室罵你），當未來實際發生的挫折長得不一樣時，大腦的神經概括就會斷裂，這個預演就失效了。
3. 失敗只是「回饋（Feedback）」，無關自我價值
預演的核心目標，是讓學員看見「即使失敗了，也不代表我沒有價值，我依然保有我的核心特質」。
四步驟具體腳本（在微證據掃描完成後執行）：
步驟一｜建立模糊與抽離的未來舞台（Set the Vague Stage）
「現在，你已經確立了你是「一個___（新身份）」的人。我想請你把視線放到未來的某一天。不需要太具體的細節，畫面可以是模糊的。就只是看著前方那個已經完全活出這個新身份的你（注意，只要看著她，不要變成她）。」
步驟二｜引入反例與挫折——極度模糊（Introduce the Counter-example）
「在這個模糊的未來裡，事情並沒有照著計畫進行。她遇到了一個很大的挫折，或者是別人對她的否定。這是一次「失敗」。」
步驟三｜觀察資源調用並打字錨定（Observe & Anchor）
「看著那個未來的你。因為她已經深信自己是「一個___（新身份）」的人，面對這個挫折時，她不但沒有陷入自我懷疑，反而調用了___（Week 1 找到的核心價值觀）來回應。告訴我，你看見那個未來的她，是用什麼樣的姿態或行動來面對這個失敗的？她做了什麼？」
📌 讓學員打出描述——打字的物理動作完成了神經預演，大腦生成新迴路：「失敗發生 → 啟動核心價值 → 做出有資源的行動」。
步驟四｜鞏固免疫力（Consolidate the Immunity）
「我聽到了。當你看到她能夠把失敗當作純粹的「回饋（Feedback）」，而不是對自我價值的打擊時——現在的你，對於未來去採取行動，感覺是不是變得更踏實、更沒有恐懼了？」
三、怨恨 / 指責卡點處理（補充第三週家族語錄信念辨識）
適用位置：所有模組第三週「步驟一 / 步驟二」——當學員唸出語錄後進入指責模式（反覆說「都是他們的錯」「如果不是他們…」），在繼續「正向意圖」之前先做這四步驟轉化。
怨恨 / 指責卡點處理（家族語錄工作中的特殊情況）（1對1 Session 版）
▲ 新增  新增——當學員在語錄溯源時陷入「都是他們的錯」的指責模式（情緒解碼文件）
指責會讓學員陷入「無能為力」的受害者狀態——等於宣告問題在別人身上，自己無法控制局面，只能被動等待他人改變。當學員反覆說「都是他/她的錯」「如果不是他們，我早就……」時，啟動以下四步驟轉化。
第一步｜停止指責，拿回情緒的所有權（Take Ownership）
底層邏輯：不評判她的指責，不評判指責的對象。先承認：「這是她的感覺。」
「「你說的那些傷，是真實的。我不是要你假裝不痛，或者說他們做的是對的。我想問你的是——那個在你心裡的憤怒和委屈，那是你的感覺，還是他們的感覺？」」
📌  讓學員說出「是我的感覺」。這一步讓她拿回控制權——外在的人事物不會直接把情緒塞進你心裡，情緒是你對刺激做出反應後的結果。
第二步｜挖掘怨恨背後的正向意圖（Positive Intent of Resentment）
底層邏輯：所有情緒背後都有一個正向意圖。怨恨往往伴隨著對「不公平」或「對與錯」的執著。
「「那個怨恨的情緒，在試圖為你做什麼？它是想保護你不再次受傷，還是渴望獲得公平與尊重？問問它，它在保護哪一個你？」」
📌  讓學員說出那個正向意圖（通常是：「保護我」「讓我不再受傷」「渴望被公平對待」）。
第三步｜從「逃避」翻轉為「追求」（Away-from → Toward）
底層邏輯：怨恨的正向意圖通常用否定句表達：「我不想受傷」「我不想被這樣對待」。潛意識無法處理否定句。
「「你說你不想受傷，不想再被這樣對待。如果你不想受傷——那你真正想感受到的是什麼？是平靜？是被看見？還是真實的連結與愛？」」
📌  強制轉向正向渴望。一旦說出「我真正想要的是平靜／連結／自由」，焦點就從指責轉向了她能控制的事。
第四步｜行為對齊，重新啟動（Align Behavior with Values）
底層邏輯：怨恨的背後，隱藏著她極度在乎但未被滿足的價值觀。
「「你說你真正想要的是___（例如：平靜）。如果繼續緊抓著這個怨恨，它會帶你更靠近這個平靜嗎？還是更遠？那個選擇放下怨恨的你——她是一個什麼樣的人？」」
📌  當她把焦點放在她能控制的事物上，並開始問「我能做什麼」而不是「他們做了什麼」，怨恨所帶來的無力感就會消散。
★  重要守則：四步驟結束後，不要立刻推進到「新任務」。先讓學員在「我真正想要的是___」這個空間裡多待一下，再問「那個你真正想要保護的自己，她是一個什麼樣的人？」——這條線接回 SC 層次，不是接回語錄分析。
