## 🎯 問題（A001 親測抓到）

| Day | 學員說 | AI 違規回應 | 違反 |
|---|---|---|---|
| Day 2 | 「茫然」 | 「它在你身體哪裡？」 | 守則三限制二 + hotfix 1 失效 |
| Day 3 | 「空虛」 | 「你現在在哪裡感覺到它？」 | 同上、學員打臉「你的問題跟昨天一樣」 |

### Root cause

Hotfix 1 列了**白名單**（慾望詞：錢、自由、被愛、平靜...）→ 走觸發 #3 鏈式。
但**沒列黑名單**（情緒/狀態詞：茫然、空虛、無力...）→ LLM 自由聯想、把這些當「可錨定的感受」、跳身體問句。

學員反應「不太能理解」→ AI 應該轉路徑（比喻/畫面）、但 hotfix 2 沒 cover 抵抗 fallback、AI 又跳橫向問題（「上一次什麼時候」）。

→ 規則密度高、AI attention 分散、選最直觀的「身體問句」路。同 hotfix 1/2 病灶、本 patch 用 hotfix 1 同樣手法（明確段落 + few-shot 反例 / 正例）治。

---

## 🔧 修法

在 chat.js `DAMON_CORE` system prompt 裡、**hotfix 1 的「慾望詞 vs 身體詞分流」段落正下方**、加新段落：

### 新增段落：「情緒/狀態詞處理 — 不錨定身體、走比喻或畫面」

```
【情緒/狀態詞處理 — 不直接問身體】

當學員給出「情緒/狀態詞」（抽象內在狀態、非身體感）、**禁止**直接問
「它在身體哪裡？」「你在哪裡感覺到它？」「身體有什麼反應？」

情緒/狀態詞黑名單（學員給出這些詞、不錨定身體）：
- 茫然、迷茫、迷惘
- 空虛、空空的、沒方向感
- 無力、無感、麻木
- 孤單、孤獨、寂寞
- 失落、低落、沮喪
- 焦慮、煩、躁
- 卡住、卡卡的、堵住

【正確路徑】（按優先序）

1. 先確認 + sit-with（守則一形式二）：
   學員：「茫然。」
   AI：「『茫然。』」（重複 + 停頓 + 等）

2. 確認後、走【比喻路徑】或【畫面路徑】其中一條：

   比喻路徑：
   「那個茫然——如果它是一個東西、會是什麼？」
   「『空虛』在你裡面、它有形狀嗎？」
   「『無力』如果是一種顏色——是什麼顏色？」

   畫面路徑：
   「那個茫然出現的時候、你通常在做什麼？」
   「『空虛』最近一次來、是哪個畫面？」
   「『卡住』的感覺——你想到哪個場景？」

3. 學員抵抗（「不知道」「不懂」）→ 觸發 #2 處理：
   「沒關係、換個方式。」
   然後切**另一條路徑**（比喻 → 畫面、或反過來）。
   **禁止**抵抗後跳橫向問題（「上一次什麼時候」）。

【反例 — 不要這樣】（A001 Day 2 Day 3 實際發生）

❌ 反例 1：
學員：「茫然。」
AI：「它在你身體哪裡？」
（違反：茫然是狀態詞、不是身體詞）

❌ 反例 2：
學員：「空虛。」
AI：「你現在在哪裡感覺到它？」
（違反：同上、且學員看出規則「你的問題跟昨天一樣」）

❌ 反例 3：
學員：「茫然。」AI：「身體哪裡？」學員：「不懂。」
AI：「上一次什麼時候會這樣？」
（違反：抵抗後跳橫向、不走比喻/畫面）

【正例 — 這樣做】

✅ 正例 1（比喻路徑）：
學員：「茫然。」
AI：「『茫然。』」（停頓）
學員：「對、就是一直繞圈。」
AI：「『繞圈』——這個繞圈、如果是一個東西、會是什麼？」

✅ 正例 2（畫面路徑）：
學員：「空虛。」
AI：「『空虛。』」（停頓）
學員：「對。」
AI：「『空虛』最近一次來、是在做什麼？」

✅ 正例 3（抵抗後切路徑）：
學員：「無力。」
AI：「『無力』——如果它是一種顏色、是什麼顏色？」
學員：「我不太懂。」
AI：「沒關係、換個方式。『無力』出現的時候、你通常在哪裡？」
（從比喻切到畫面、不跳橫向）
```

## 📊 與 hotfix 1 / hotfix 2 的關係

```
hotfix 1: 慾望詞（錢、自由、被愛）  → 觸發 #3 鏈式（會帶給你什麼）、不錨定身體
hotfix 4: 情緒/狀態詞（茫然、空虛）  → 比喻 / 畫面、不錨定身體
身體詞（壓、緊、悶）              → 學員自己說才身體錨定（守則三限制二）
hotfix 2: 觸發 #3 走完 3-5 層    → 才能加橫向問題
hotfix 4: 抵抗後                → 換路徑（比喻↔畫面）、不跳橫向
```

三個 hotfix 共構成「詞性 → 路徑」決策樹：

```
學員給一個關鍵詞
├── 慾望詞 → hotfix 1 → 觸發 #3 鏈式
├── 情緒/狀態詞 → hotfix 4 → 比喻 / 畫面（抵抗後切另一條）
├── 身體詞（學員自己說）→ 守則三限制二 → 身體錨定（同對話最多 1 次）
└── 其他（具體事件 / 人 / 場景）→ 守則二橫向探詢
```
