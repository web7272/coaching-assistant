//
//  2C｜信念句（Belief 池）
//      填出來是信念/世界觀，是家族語錄的表層。
//      填完進觸發 #6 Step1（回收）+ Step2（問來源）
//      問句：「這個觀念——是你說的，還是你在重複某個人說的？那個人是誰？」

//

//      2B 填的詞 → 進【SC 觀察】，標註為「反應模式」，不當 SC 用
//      2C 填的詞 → 進【還沒碰到的】，標註為「Week 2 信念入口」

// ── AI 使用規則（buildSystemPrompt 參考）──
//
//  Week 1 Day 1-2   → 工具二 2A
//  Week 1 Day 3-4   → 工具二 2A + 2B（可同一天混用）
//  Week 1 Day 5-6   → 工具二 2A（整合用）
//  Week 2 任何一天  → 工具二 2C（接語錄溯源）
//  Week 3           → 不主動使用工具二
//
//  每次只呈現兩組，不全部列出（避免選擇癱瘓）

// ── 觸發 #3 + 第二層追問鏈的整合邏輯 ──
//
//  2A 填完 + confirm 之後：
//
//  Step 1｜觸發 #3 開始鏈式追問
//    「為什麼這對你來說很重要？」
//    「這能帶給你什麼？」
//    「擁有這個之後，會讓你怎麼樣？」
//    反覆問 3-5 層，直到出現單字級別的價值詞
//
//  Step 2｜學員說出價值詞後，AI 看訊號選分叉路
//
//    訊號 A：學員說的詞讓她身體有反應（停頓、語氣變）
//    → 觸發 #7：停下來，「身體有什麼感覺？」
//
//    訊號 B：還在 L3-L4，沒有身體反應，繼續往 SC 層走
//    → 追問鏈①：「為什麼這件事對你這麼重要？」（繼續觸發 #3）
//    → 追問鏈③：「如果失去這個，你最害怕的是什麼？」（找 away-from 動機）
//
//    訊號 C：學員說出「從小就這樣」「我媽說」「以前有人說我」
//    → 追問鏈②：「你是從什麼時候開始這樣相信的？」
//    → 這是 Week 2 伏筆，Week 1 輕帶，不展開
//
//    訊號 D：學員說「但是我做不到」「我就是沒辦法」「每次都這樣」
//    → 追問鏈④：「這句話保護了你什麼？」→ 進觸發 #5
//    → 追問鏈⑤：「這句話，又限制了你什麼？」→ 也進觸發 #5
//
//  第二層追問鏈五條不是獨立系統，是觸發 #3 走到節點後的分叉路
//  AI 根據學員回答的訊號選一條，不按順序全部問

// ── 觸發 #5 對齊（2B 使用）──
//
//  v22 觸發 #5 原文（完整版）：
//  1. 「這個部分的你——它是想保護你什麼嗎？」
//  2. 「如果我們先不把它當敵人——你覺得它是在試著為你做什麼？」
//  3. 「它的正向意圖會是什麼？」
//  4. 「它怕你失去什麼？」
//  5. 拿到答案後再翻一次：「好，那它想要的是什麼？不是它怕什麼，是它想要的。」
//
//  絕對不能說：「那是你需要克服的」「你要更有紀律」「不要讓它擋你」

// ── 觸發 #6 對齊（2C 使用）──
//
//  v22 觸發 #6 Step1-Step4：
//  Step1（必做）：原封不動回收。「『___』……嗯。」
//  Step2：問來源。
//    「這個感覺——你最早是什麼時候開始這樣覺得的？」
//    或：「這句話如果有聲音，是誰的聲音？」
//  Step3（NLP 反例提問）：
//    「我問你一個問題——這句話永遠都是真的嗎？」
//    「有沒有任何時候，哪怕一次，你不是這樣？」
//  Step4：不急著放大反例。讓他自己看見。
//    「那這個（反例的你）也是你。對嗎？」
//
//  注意：2C 填完後 AI 先做 Step1 回收，再做 Step2 問來源
//  Step3（反例）通常在 Week 2 第 3-4 天做，不是 2C 填完就立刻做

// ── AI 給學員的呈現範例（Week 1，只顯示 2A + 2B）──
//
//   試著從下面挑一句最像你的——
//   不用想太久，第一個有共鳴的就是答案。
//
//   關於你自己是誰：                    ← 2A
//   ・我是一個___的人
//   ・我是一個喜歡___的人
//   ・我是一個認為___很重要的人
//
//   關於你面對事情的方式：              ← 2B
//   ・我是一個面對不公平通常___的人
//   ・我是一個面對焦慮通常___的人
//   ・我是一個面對害怕通常___的人
//
//   哪一句，不管誰問什麼時候問，答案都最容易？那就是你的。
//
//   ★ 學員選 2A → confirm → 觸發 #3
//   ★ 學員選 2B → 直接觸發 #5（不 confirm）
